新点 CA 及签章方案图解

广州一网通办 EpQzFileServer 签章引擎与 casharedemo 接入层的架构、云签章流向、接入协议与安全风险一页看懂。

EpQzFileServer · Spring Boot 1.5 casharedemo · Spring Boot 2.3 反编译 + 源码审阅

01两层结构

方案分「接入层」与「签章引擎」两层；引擎对外提供签章能力，接入层对接业务与全国 CA 互认平台。移动 CA 走扫码，介质 CA 走 USB Key。

签章引擎
EpQzFileServer
PDF/OFD 预览·签章·验章·关键字定位·云签·文件解密。靠 EpSignature.lic 授权。
接入 / 中间层
casharedemo
广州一网通办 Demo，转发业务请求，对接引擎与 CA 互认平台。
混淆情况
主程序 Allatori 字符串加密已全部还原；三个引擎依赖库未混淆，源码可直读。

02系统架构图

浏览器 / 移动端 → casharedemo → EpQzFileServer → 云签平台 / CA 互认平台。虚线框标注「必须同域部署」的两个服务。

本方 (同域) 第三方平台 文件存储

同域要求来自引擎拿到加密路径 p 后会回到调用方地址取文件（红色回调线）。

03云签章流向图

一次 /epcaqzdemo/cloudseal 请求从下载文件到回传结果的完整时序。关键字每命中一处就调一次引擎签章接口。

⑨ 的「写回」是否覆盖原文件由引擎配置 isCoverSrc 决定；⑩ 回传固定取 1.pdf，仅当 isCoverSrc=true 时它才是已签章版本。

04接入协议要点

对接 EpQzFileServer 必须理解的两个凭据，和 CA 互认平台的签名算法。

token（t）
appKey@HmacSHA1(P2,appSecret)@P2
P2=「当前时间+5分钟」的 Base64，5 分钟失效。
路径（p）
文件相对路径经 SM4-ECB 加密；密钥 = appsecret（与 token 同一把）。
同域部署
引擎凭 p 回调调用方取文件，两服务必须同域，appsecret 两端一致。
CA互认签名
7字段 TreeMap 排序 → 加盐(时间戳3位+nonce3位) → HmacSM3。入口 /CAShare/Components。

05问题与风险

代码审阅结论，按严重度排列；未经实际攻击验证。标注「需平台方确认」者取决于云签平台是否做用户级授权。

高危

密钥可在浏览器直接拿到

GET /ca-share-config 明文返回 clientSecret / signatureSecret，拿到即可伪造 CA 平台签名请求。

高危

密钥硬编码且已泄露

CA / epqz 密钥、多套 appkey、pfx 密码 000000 明文写入 yml 并打包；jar 内还带第三方 .pfx 证书。SM4 密钥复用 appsecret。

高危

token 与文件路径可伪造

HMAC 与 SM4 共用 appsecret，而该值明文在 jar 中，拿到 jar 即可自造有效 token 与路径。

高危

SSRF + 路径穿越

f/s/targetUrl 可请求任意 URL 且关闭证书校验；多数走 SM4 路径的接口未校验 ../。

中危

鉴权缺失或形同虚设

/testpdfservice/doAction 等 token 失败仅记日志仍继续；/demoservice 与多数 /common 接口无校验。

中危

签章身份由调用方声明

organization/user_id 取自请求，可指定任意单位印章 —— 实际可行性需平台方确认。

中危

任意删文件 / 信息泄露

DELETE /delete-all-pdf-files、/fs-diagnostic、/get-workspace-logs 对外开放；CORS * 且允许携带凭证。

中危

并发串数据 / 全局关闭证书校验

httpUrl 单例成员每请求改写、多个静态字段非线程安全；ignoreSsl() 改全 JVM 默认校验器。

质量

死代码 · 文档不符 · 组件过旧

个人签章分支恒不可达；文档与返回码不符；Spring Boot 1.5 / fastjson 1.2.83 已停维，双日志框架 + rebel.xml 残留。

06立即处理与整改

⏰ 授权即将到期

EpSignature.lic 有效期 2025-06-17 ~ 2026-12-31。到期瞬间仅后台线程抛异常，运行中进程不会立即停；但到期后一旦重启即无法签章。请立即联系厂商续期。

  • 删除 / 关闭 /ca-share-config、/fs-diagnostic、/delete-all-pdf-files。
  • 对 f/s/targetUrl/fileUrl 加域名白名单。
  • 所有对外接口加统一鉴权；token 校验失败必须拦截而非仅记日志。
  • 解密路径统一做 ../ 穿越校验（推广 FileValidator）。
  • httpUrl 改局部变量；审查静态字段并发安全；不要全局 ignoreSsl()。
  • 密钥移出代码库并更换已泄露的所有密钥；确认 isCoverSrc=true。
  • 升级 Spring Boot / Tomcat / fastjson；清理重复日志框架与 rebel.xml。
