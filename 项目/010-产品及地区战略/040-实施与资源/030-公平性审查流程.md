# 公平性审查流程

## 核心结论

- 该流程把公平性审查拆成两条闭环：线上审查链路负责文件下载、解析、检测点匹配、语义判断和结果输出；离线训练链路负责历史数据标注、模型训练、指标评估和规则迭代。
- 核心不是单独依赖大模型，而是“结构化解析+正则/SeqGPT抽取+语义判断+黑白名单+业务规则”的组合式引擎，以降低误报并保持结果可解释。
- 人工贯穿标注纠正、专家复核和规则优化，模型只输出辅助判断；审查结论应同时保留原文证据、命中检测点、判断理由和规则/模型版本。
- 流程已给出工程化路线：半自动标注形成CSV/JSONL数据，使用ModelScope ms-swift微调，按Accuracy、Recall、F1评估，再以PyTorch/CUDA和Flask REST服务部署。

## 关键论据

- 在线链路从招标文件进入自动化申请服务，经网关或SDK下载PDF，支持挂载路径，再解析为结构化数据并提取关键信息。
- 系统遍历审查检测点并与平台检测项匹配，随后通过正则表达式和SeqGPT抽取指标，对敏感内容做语义判断。
- 黑名单用于识别明确违规模式，白名单用于排除合理例外；最终再叠加业务规则判断，形成合规检测和业务结果。
- 训练链路从历史项目文件开始，经过材料分类、任务分派、结构化标注、结果标注、清洗去重和数据标准化，再进入模型训练与评估。
- 标注采用基础模型预提取加人工纠正的半自动方式；训练后通过准确率曲线和回归对比决定是否调整流程、规则或样本。
- 图中提示词示例要求模型以专业招标审查人员身份判断“违规/不违规”，并同时给出原因和对应原文，体现证据化输出要求。
- 流程末端设置专家复核和持续优化，说明检测点、规则、名单和模型需要版本化迭代，而非一次性固化。

## 方法论名称

- 规则与模型融合审查
- 正则表达式加SeqGPT指标抽取
- 黑白名单误报抑制
- 基础模型预标注加人工纠正
- 多指标模型评估（Accuracy、Recall、F1）
- 训练—评估—回归—专家复核闭环

## 可复用模板

- 审查结果对象：文件、条款位置、原文、检测点、提取指标、命中规则、语义结论、理由、置信度、模型版本、规则版本和人工复核状态。
- 检测点配置表：检测点编码、法规依据、正则、语义提示词、黑名单、白名单、适用品类、严重级别和生效时间。
- 标注数据规范：项目类型、文本片段、实体、分类标签、阅读理解答案、标注人、复核人、争议状态和数据版本。
- 模型验收表：Accuracy、Precision、Recall、F1、误报率、漏报率、回归样本结果、推理时延和上线阈值。
- 迭代闭环：新增案例→模型预标→人工纠正→清洗标准化→微调→离线评估→回归测试→灰度发布→专家反馈。
