# 目录及文件组织规范

## 框架整体目录

```
ejs.m8.mobileframe
    ├── dist                        打包编译过后，开发、生产模式下的代码
    │   ├── dev                     dev调试模式下的代码
    │   │   ├── mp-weixin           dev调试模式下的微信小程序IDE加载工程
    │   │   ├── mp-alipay           dev调试模式下的支付宝小程序IDE加载工程
    │   ├── build                   构建后的代码
    │   │   ├── h5                  构建后的H5工程
    │   │   ├── mp-weixin           构建后的微信小程序IDE加载工程
    │   │   ├── mp-alipay           构建后的支付宝小程序IDE加载工程
    ├── build                       devServer 与 webpack 构建配置
    ├── src
    │   ├── common                  存放所有公共代码
    │   ├── components              存放业务相关组件库
    │   ├── pages                   存放业务页面相关代码
    │   ├── shared                  公共配置、config.js、默认引入资源等
    │   ├── static                  存放应用引用的本地静态资源（如图片、视频等）的目录，注意：此目录不会被 webpack 编译
    │   ├── main.js                 Vue初始化入口文件
    │   ├── App.vue                 应用配置，用来配置App全局样式以及监听
    │   ├── manifest.json           配置应用名称、appid等信息
    │   ├── page.json               配置页面路由、导航条等页面类信息
    │   └── uni.scss                这里是工程内置的常用样式变量 
```

**Tips**
- `static` 目录下的 `js` 文件不会被编译，如果里面有 `es6` 的代码，不经过转换直接运行，在手机设备上会报错。
- `css`、`scss` 等资源不要放在 `static` 目录下，建议这些公用的资源放在 `common` 目录下。


## components目录

```
ejs.m8.mobileframe
    ├── src
    │   ├── components
    │   │   ├── custom_components
    │   │   │   ├── [components_name].vue
```

`custom_components`下的组件为业务自定义组件

框架提供的跨端UI组件通过npm依赖引入，不再暴露在项目工程中

## pages目录

```
ejs.m8.mobileframe
    ├── src
    │   ├── pages
    │   │   ├── [module_name]                 // 以模块名命名的文件夹
    │   │   │       ├── css                   // 当前模块下的css样式目录
    │   │   │       ├── [module_name_A].vue   // 模块单文件组件
    │   │   │       ├── [module_name_B].vue   // 模块单文件组件
    │   │   │       ├── [module_name_C].vue   // 模块单文件组件
    │   │   │       ├── router.js             // 此模块对应的路由定义
    │   │   │       ├── store.js              // 此模块对应的状态管理定义
    │   │   │       ├── mock.js               // `v8.2.15`新增，模块对应的mock数据定义
```

以项目 `模块名` 来创建对应文件夹

`router.js` 每一个模块下的路由配置，使用方法参考框架文档 [Vue Router 的使用](http://app.epoint.com.cn/m8mpdoc/?file=011-vuex%E4%B8%8Evue-router%E7%9A%84%E4%BD%BF%E7%94%A8/vue-router%E7%9A%84%E4%BD%BF%E7%94%A8)

`store.js` 每一个模块下的状态管理配置，使用方法参考框架文档 [Vuex 的使用](http://app.epoint.com.cn/m8mpdoc/?file=011-vuex%E4%B8%8Evue-router%E7%9A%84%E4%BD%BF%E7%94%A8/vuex%E7%9A%84%E4%BD%BF%E7%94%A8)

`mock.js` 每一个模块下的Mock配置，使用方法参考框架文档 [Mock 的使用](http://app.epoint.com.cn/m8mpdoc/?file=012-Mock%E7%9A%84%E4%BD%BF%E7%94%A8/Mock%E7%9A%84%E4%BD%BF%E7%94%A8)

## shared目录

```
ejs.m8.mobileframe
    ├── src
    │   ├── shared
    │   │   ├── boot.js             // 默认加载项资源
    │   │   ├── config.js           // 全局业务配置文件
```

`boot.js` 默认加载资源项，在各个模块入口，通过 `import` 引入

`config.js` 全局业务配置文件

## static目录

`static` 目录下的 `js` 文件不会被编译，如果里面有 `es6` 的代码，不经过转换直接运行，在手机设备上会报错。

`css`、`scss` 等资源不要放在 `static` 目录下，建议这些公用的资源放在 `common` 目录下。

`static` 目录下的资源会在构建后被拷贝到对应的构建目录下，例如：

```
ejs.m8.mobileframe
    ├── dist
    │   ├── build
    │   │   ├── h5
    │   │   │   ├── static
    │   │   │   │   │   ├── js
    │   │   │   │   │   │   ├── [file_name].js
    ├── src
    │   ├── static
    │   │   ├── js
    │   │   │   ├── [file_name].js
```
