# 工程自定义配置

## 前言

移动前端跨端框架支持工程自定义webpack配置，以满足不同工程的需求。

## 配置文件位置

```
ejs.m8.mobileframe
    ├── build                       devServer 与 webpack 构建配置
    │   ├── base.config.js          用于配置调试、生产环境是否开启showcase
    │   ├── dev.server.js           跨端框架devServer配置
    │   ├── index.js                自定义webpack配置入口
```

## base.config.js

```js
module.exports = {
    isDevBuildShowcase: 0,
    isProBuildShowcase: 0
};
```

用于配置调试、生产环境是否开启showcase。

注意：修改后需要重启服务或重新构建。仅在H5端生效。

## dev.server.js

```js
module.exports = {
    openPage: process.env.devName ? process.env.devName : '',
    // h5环境强制打开浏览器
    open: process.env.UNI_PLATFORM === 'h5',
    // 设置服务器的主机号，默认是 localhost
    host: '0.0.0.0',
    // 端口号，被占用的话会自动选择别的端口
    port: '8080',
    // 是否实时刷新
    inline: true,
    // 是否启用webpack的热模块替换功能
    hot: true,
    // 是否启用 gzip 压缩
    compress: true,
    overlay: true,
    // 去除dev下进度输出信息
    progress: false,
    // 是否现实捆绑包中的错误
    stats: 'errors-only',
    // 代理，支持 http-proxy-middleware 所有配置
    // 此配置会与Config.devServerProxy进行合并
    proxy: null,
    // 是否开启https服务，浏览器中不在localhost下测试百度地图组件时需要开启
    https: false
};
```

跨端框架devServer配置。

注意：修改后需要重启服务或重新构建。

## index.js

```js
const baseConfig = require('./base.conf');
const devServer = require('./dev.server');
// 自定义 Webpack 配置
const webpackChain = () => {};
// 默认情况下 babel-loader 会忽略所有 node_modules 中的文件。如果你想要通过 Babel 显式转译一个依赖，可以在这个选项中列出来。
const transpileDependencies = [];


module.exports = {
    baseConfig,
    devServer,
    webpackChain,
    transpileDependencies
};
```

自定义webpack配置入口。

### webpackChain

跨端框架会在自己的webpack配置之后调用此配置。

webpackChain配置方式参考：[https://cli.vuejs.org/zh/guide/webpack.html#%E9%93%BE%E5%BC%8F%E6%93%8D%E4%BD%9C-%E9%AB%98%E7%BA%A7](https://cli.vuejs.org/zh/guide/webpack.html#%E9%93%BE%E5%BC%8F%E6%93%8D%E4%BD%9C-%E9%AB%98%E7%BA%A7)

### transpileDependencies

`v8.3.9`新增。跨端框架会与自己的babel配置进行合并。

transpileDependencies配置方式参考：[https://cli.vuejs.org/zh/config/#transpiledependencies](https://cli.vuejs.org/zh/config/#transpiledependencies)

注意：修改后需要重启服务或重新构建。
