# 主题切换

M84 移动端框架内置了基于 CSS 变量的主题切换能力，支持自定义主题注册及切换。框架内置了一套完整的 EUI4 默认主题变量（`theme-base`），开发者可基于此注册自定义主题。框架在编译时自动为每个路由页面外层包裹 `<theme-provider>` 组件，页面内所有使用 CSS 变量的样式均可响应主题变化，无需手动处理。

## 目录结构

主题相关代码位于框架源码 `src/theme` 目录下：

```
ejs.m8.mobileframe
    └── src
        ├── theme
        │   ├── index.ts                 ThemeManager 核心类
        │   ├── theme-provider.vue       主题包裹组件
        │   └── css
        │       ├── index.scss           主题样式汇总入口
        │       ├── theme-base.scss      EUI4 默认主题变量（内置，完整）
        │       ├── theme-0.scss         自定义主题示例
        │       └── theme-1.scss         自定义主题示例
        ├── uni.scss                     uniapp框架变量桥接（映射 $uni-* 变量到 eui4 变量）
        └── shared
            └── boot.ts                  监听原生主题切换事件
```

## 工作原理

### 1. 自动包裹 theme-provider

框架编译阶段（`vue-inset-plugin`）会自动将每个路由页面的模板内容包裹在 `<theme-provider>` 标签内：

```html
<!-- 编译前：pages/demo/index.vue -->
<template>
    <view class="container">...</view>
</template>

<!-- 编译后（自动包裹） -->
<template>
    <theme-provider>
        <view class="container">...</view>
    </theme-provider>
</template>
```

`theme-provider` 组件会根据当前主题动态添加 CSS 类名和内联变量：

```html
<div :class="['theme-base', 'theme-' + 当前主题名]" :style="当前主题的CSS变量">
    <slot></slot>  <!-- 页面内容 -->
</div>
```

### 2. CSS 变量分层架构

主题系统基于 CSS 变量的覆盖机制工作：

| 层级 | 文件 | CSS 类名 | 说明 |
| --- | --- | --- | --- |
| 默认主题 | `theme-base.scss` | `.theme-base` | 内置的完整 EUI4 默认变量，始终生效 |
| 自定义主题 | 开发者自定义 | `.theme-{name}` | 覆盖默认主题中需要调整的变量 |

框架内置了 `theme-0.scss` 和 `theme-1.scss` 作为自定义主题的示例文件，开发者可以参考它们编写自己的主题文件。

切换主题时，`theme-provider` 同时挂载 `.theme-base` 和 `.theme-{name}` 两个类名，自定义主题层变量覆盖默认层同名变量。

## API：EUIThemeManager

`EUIThemeManager` 是一个单例对象，通过 `import { EUIThemeManager } from '@/theme'` 引入。

### 属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `theme` | `string`（只读） | 当前主题名称，默认 `'base'` |
| `themeVars` | `Record<string, string>`（只读） | 当前主题的 CSS 变量映射表 |

### 方法

#### setTheme(type, vars?)

切换当前主题。

```typescript
EUIThemeManager.setTheme(type: string, vars?: Record<string, string>): void
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | `string` | 是 | 主题名称，如自定义的 `'ocean'`，或示例中的 `'0'`、`'1'` |
| `vars` | `Record<string, string>` | 否 | 切换的同时注册自定义 CSS 变量 |

如果 `type` 为空，将回退到 `'base'` 默认主题。

#### registerTheme(type, vars)

注册一个新的自定义主题（或覆盖已有主题的变量）。

```typescript
EUIThemeManager.registerTheme(type: string, vars: Record<string, string>): void
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | `string` | 是 | 主题名称 |
| `vars` | `Record<string, string>` | 是 | 该主题的 CSS 变量映射表 |

#### unregisterTheme(type)

注销一个已注册的主题。

```typescript
EUIThemeManager.unregisterTheme(type: string): void
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | `string` | 是 | 要注销的主题名称 |

#### hasTheme(type) 

v8.4.6-beta.1 开始支持。

检查指定主题是否已注册。

```typescript
EUIThemeManager.hasTheme(type: string): boolean
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | `string` | 是 | 要检查的主题名称 |
| **返回值** | `boolean` | - | `true` 表示已注册，`false` 表示未注册 |

## 使用示例

### 切换主题

```typescript
import { EUIThemeManager } from '@/theme';

// 切换到已注册的主题
EUIThemeManager.setTheme('1');

// 切换回默认主题
EUIThemeManager.setTheme('base');
```

### 注册并使用自定义主题

```typescript
import { EUIThemeManager } from '@/theme';

// 1. 注册自定义主题
EUIThemeManager.registerTheme('ocean', {
    '--e-color-primary': '#006994',
    '--e-color-primary-light-3': '#338db3',
    '--e-color-primary-light-5': '#80b4d4',
    '--e-color-primary-light-7': '#b3d4e8',
    '--e-color-primary-light-8': '#d9eaf3',
    '--e-color-primary-dark-2': '#005475',
    '--e-text-color-primary': '#1a1a2e'
});

// 2. 切换到自定义主题
EUIThemeManager.setTheme('ocean');

// 3. 不再需要时注销
EUIThemeManager.unregisterTheme('ocean');
```

### 切换主题并同步传入变量

```typescript
// setTheme 的第二个参数可以同时传入自定义变量
EUIThemeManager.setTheme('base', {
    '--e-color-primary': '#ff6600',
    '--e-text-color-primary': '#333333'
});
```

### 在业务样式中使用主题变量

在 Vue 组件的 `<style>` 中直接使用 CSS 变量：

```vue
<template>
    <view class="card">
        <text class="title">标题</text>
    </view>
</template>

<style lang="scss" scoped>
.card {
    background: var(--e-fill-color);
    border: var(--e-border) var(--e-border-color);
    border-radius: var(--e-border-radius-base);
    padding: var(--e-space-xl);
}
.title {
    color: var(--e-text-color-primary);
    font-size: var(--e-font-size-medium-l);
}
</style>
```

## 原生容器主题联动

框架在 `boot.ts` 中提供了监听原生容器主题切换事件的示例代码，当 EJS 原生容器触发 `onThemeChanged` 事件时，会调用 `EUIThemeManager.setTheme(result.type)` 切换主题类型：

```typescript
if (ejs.os.ejs) {
    ejs.event.registerEvent({
        key: 'onThemeChanged',
        success: function (result) {
            EUIThemeManager.setTheme(result.type);
        }
    });
}
```

当前仅完成了事件监听与主题类型切换的对接，具体如何根据容器返回的信息注册对应的主题变量，需根据实际容器对接情况由开发者自行补充。

## 内置 CSS 变量参考

默认主题的所有 CSS 变量定义在框架源码 `src/theme/css/theme-base.scss` 中，涵盖颜色、文本、边框、填充、字体、圆角、间距、阴影等分类，变量统一使用 `--e-` 前缀。自定义主题时可按需覆盖其中的变量，完整变量列表请直接查看该文件。
