# 三方平台安装构建跨端框架

# 背景

由于移动前端跨端框架的核心依赖为公司内部私有化依赖，安装 `npm install` 时需要在公司内网环境。

导致如果需要将跨端框架代码上传到一些需要对代码工程构建的三方平台时，无法安装框架依赖。

# 解决办法

目前思路为在本地工程安装依赖时，指定 npm 缓存目录为当前目录下的`.cache`文件夹，本地执行 `npm install`时将 npm 缓存安装到本地目录下，提交三方平台时将 npm 缓存提交到三方平台。

缺点是提交至三方平台时需要提交 npm 缓存目录，造成提交体积变大。

# 操作过程：

## 配置修改

修改工程目录下 `.npmrc` 文件：

```bash
# 原有配置不动

# 底部增加一行配置，指定npmcache为当前目录
cache = ./.cache
```

## 安装依赖

删除 `node_modules` 目录，删除 `package-lock.json` 文件，重新执行 `npm install` 依赖安装。

## 压缩提交

安装完成后本地工程会出现 `.cache` 文件夹，将该文件夹与代码工程一起打包压缩，提交到三方平台。

---

## 注意

此时工程下的 `.cache` 目录会被代码版本管理索引，一般不需要提交到代码版本管理。此时需要将 `.cache` 目录排除在版本管理之外，可以修改 `.gitignore` 文件，增加 `.cache` 目录，忽略该目录的 git 版本管理。

如果是 svn ，同理需要忽略该文件目录。
