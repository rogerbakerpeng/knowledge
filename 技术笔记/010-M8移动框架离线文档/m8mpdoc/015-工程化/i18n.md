# 国际化

本文档详细介绍如何在跨端框架中实现国际化，包括语言文件创建、注册、使用和切换的完整流程。

## 一. 目录结构设计

首先在项目`src`目录下创建`locale`文件夹，并按照功能划分三个子目录结构：

```
├── src
│   ├── locale                    # 国际化主目录
│   │   ├── em-components         # EM组件库的补充语言文件
│   │   │   ├── index.js          # 语言包导出文件
│   │   │   └── zh-Hant.json      # 繁体中文语言包（EM组件库已内置英文、简体中文语言包）
│   │   ├── custom                # 业务代码的语言文件
│   │   │   ├── en.json           # 英文业务语言包
│   │   │   ├── index.js          # 语言包导出文件
│   │   │   ├── zh-Hans.json      # 简体中文业务语言包
│   │   │   └── zh-Hant.json      # 繁体中文业务语言包
│   │   ├── en.json               # 框架全局及路由配置语言（英文）
│   │   ├── zh-Hans.json          # 框架全局及路由配置语言（简体中文）
│   │   └── zh-Hant.json          # 框架全局及路由配置语言（繁体中文）
│   └── main.js                   # 入口文件
```

### 目录说明

| 目录/文件        | 用途说明                                                     |
| :--------------- | :----------------------------------------------------------- |
| em-components    | 存放 EM 组件库的补充语言文件，用于扩展或修改组件库默认文案   |
| custom           | 存放业务代码的语言文件，用于业务页面和组件的国际化           |
| 根目录 json 文件 | 存放框架 manifest.json、pages.json 和 router.js 中使用的语言 |

## 二. 语言文件创建

### 2.1 EM 组件库语言文件

EM 组件库已内置英文（en）和简体中文（zh-Hans）语言包，无需重复添加。如需扩展或修改语言包，可在`locale/em-components`目录下创建相应语言文件。以下以繁体中文简单示例，完整组件库语言配置可在 `node_modules\@epoint-mrc\em-components\src\components\locale\i18n\zh-Hans.json` 获取：

**繁体中文语言包（zh-Hant.json）**

```json
// src/locale/em-components/zh-Hant.json
{
    "em-cascader": {
        "placeholder": "請選擇"
    },
    "em-picker": {
        "cancel": "取消",
        "confirm": "確認"
    }
}
```

**语言包导出文件（index.js）**

```javascript
// src/locale/em-components/index.js
/**
 * EM组件库语言包导出文件
 * 将所有语言包整合为messages格式导出
 */
import zhHant from './zh-Hant.json';

const messages = {
    'zh-Hant': zhHant
};

export default messages;
```

### 2.2 业务代码语言文件

在`locale/custom`目录下创建业务语言文件，用于业务页面和组件的国际化。

项目可根据业务模块结构或页面名称组织划分语言 key 层级，例如以下 home 模块的语言 key 为`home.title`、`home.welcome`、`home.description`。

**中文语言包（zh-Hans.json）**

```json
// src/locale/custom/zh-Hans.json
{
    "home": {
        "title": "首页",
        "welcome": "欢迎使用跨端框架",
        "description": "这是一个功能强大的跨端应用框架"
    }
}
```

**英文语言包（en.json）**

```json
// src/locale/custom/en.json
{
    "home": {
        "title": "Home",
        "welcome": "Welcome to Cross-platform Framework",
        "description": "This is a powerful cross-platform application framework"
    }
}
```

**繁体中文语言包（zh-Hant.json）**

```json
// src/locale/custom/zh-Hant.json
{
    "home": {
        "title": "首頁",
        "welcome": "歡迎使用跨端框架",
        "description": "這是一個功能強大的跨端應用框架"
    }
}
```

**语言包导出文件（index.js）**

```javascript
// src/locale/custom/index.js
/**
 * 业务代码语言包导出文件
 * 将所有语言包整合为messages格式导出
 */
import en from './en.json';
import zhHans from './zh-Hans.json';
import zhHant from './zh-Hant.json';

const messages = {
    en,
    'zh-Hans': zhHans,
    'zh-Hant': zhHant
};

export default messages;
```

### 2.3 框架全局语言文件

这些语言文件无需手动导入导出，框架会自动注册并读取。

**中文语言包（zh-Hans.json）**

```json

    "index.title": "首页",
    "detail.title": "用户中心",
    "tabbar.home": "首页",
    "tabbar.user": "我的"
}
```

**英文语言包（en.json）**

```json
// src/locale/en.json
{
    "app.name": "Cross-platform Framework",
    "index.title": "Home",
    "detail.title": "User Center",
    "tabbar.home": "Home",
    "tabbar.user": "Profile"

```

**繁体中文语言包（zh-Hant.json）**

## 三. 语言文件注册

在入口文件`main.js`中注册所有语言文件，包括 EM 组件库语言、业务代码语言和框架全局语言。

注意：业务代码语言注册用到了 `vue-i18n` 插件，工程需要运行 `npm i vue-i18n@8` 安装该插件，注意安装版本。

```javascript
// src/main.js
import Vue from 'vue';
import App from './App';
import VueI18n from 'vue-i18n';

// 1. 引入EM组件库的语言文件（通过index.js统一导出）
import emMessages from './locale/em-components/index.js';

// 2. 引入业务代码的语言文件（通过index.js统一导出）
import customMessages from './locale/custom/index.js';

// 3. 注册em组件库的语言包
Locale.add(emMessages);

// 4. 注册业务语言包
Vue.use(VueI18n);
const i18n = new VueI18n({
    locale: uni.getLocale() || 'zh-Hans', // 设置默认语言，这里可以通过uni.getLocale()获取系统语言
    messages: customMessages
});

// 5. 初始化Vue实例
const app = new Vue({
    i18n,
    ...App
});

app.$mount();
```

## 四. 语言使用方法

### 4.1 业务代码中使用

#### 4.1.1 模板中使用

在 Vue 组件的模板中使用`$t()`方法进行翻译：

```html
<!-- src/pages/index/index.vue -->
<template>
    <view class="container" @click="handleClick">
        <h1>{{ $t('home.title') }}</h1>
        <p>{{ $t('home.welcome') }}</p>
    </view>
</template>
```

#### 4.1.2 脚本中使用

在 Vue 组件的脚本中使用`this.$t()`方法进行翻译：

```javascript
// src/pages/index/index.vue
export default {
    methods: {
        handleClick() {
            // 脚本中使用翻译
            ejs.ui.toast(this.$t('home.description'));
        }
    }
};
```

### 4.2 框架全局文件中使用

在`pages.json`或`router.js`中使用`%%`占位符进行翻译，框架会自动读取`locale`根目录下的语言文件。

**router.js 示例**

```js
const routes = [
    {
        path: 'pages/index/index',
        style: {
            navigationBarTitleText: '%index.title%'
        }
    },
    {
        path: 'pages/index/detail',
        style: {
            navigationBarTitleText: '%detail.title%'
        }
    }
];

// 导出路由文件
export default routes;
```

**pages.json 示例**

```json
// pages.json
{
    "tabBar": {
        "list": [
            {
                "pagePath": "pages/index/index",
                "text": "%tabbar.home%"
            },
            {
                "pagePath": "pages/user/index",
                "text": "%tabbar.user%"
            }
        ]
    }
}
```

**manifest.json 示例**

```json
// manifest.json
{
    "name": "%app.name%", // 这里一般置空，仅为示例说明
    "appid": "",
    "description": "",
    "versionName": "1.0.0",
    "versionCode": "100",
    "locale": "zh-Hans" // 设置默认语言，默认为auto，跟随系统OS语言
}
```

## 五. 语言切换实现

### 5.1 封装语言切换方法

在`locale`目录下创建`index.js`文件，封装统一的语言切换方法：

```javascript
// src/locale/index.js
/**
 * 切换应用语言
 * @param {string} lang - 语言代码，如'en'、'zh-Hans'
 */
export function setLang(lang) {
    try {
        // 1. 切换EM组件库语言
        Locale.use(lang);

        // 2. 切换业务代码语言
        if (getApp() && getApp().$vm && getApp().$vm.$i18n) {
            getApp().$vm.$i18n.locale = lang;
        }

        // 3. 切换框架全局语言
        uni.setLocale(lang);

        return true;
    } catch (error) {
        console.error('语言切换失败:', error);
        return false;
    }
}
```

### 5.2 使用语言切换

在需要切换语言时引入并使用`setLang`方法，注意必须要在Vue实例初始化完成后调用，否则会报错。

```js
import { setLang } from '@/locale/index.js';

const app = new Vue({
    i18n,
    ...App
});

app.$mount();

// 调用语言切换方法
const success = setLang(lang);
if (success) {
    ...
}
```

### 5.3 监听语言变化

可以使用`uni.onLocaleChange`监听语言变化，以便在语言切换时执行相应的逻辑：

```javascript
// 在App.vue中监听语言变化
onLaunch() {
  // 监听语言变化
  uni.onLocaleChange((locale) => {
    console.log('语言变化:', locale);
    // 可以在这里执行语言变化后的逻辑
  });
}
```

## 六、平台小程序国际化

平台小程序端国际化更多依赖小程序平台框架自身，一般而言海外用户更多使用的是H5。

**支持情况**

支持：em组件库和业务代码的语言注册和切换方案

不支持：router.js、pages.json、manifest.json等文件中的语言配置方案

**一些解决方案**

1. **动态设置标题**

   router.js 中不能直接配置动态标题，但是可以通过调用 API 来实现。例如，在页面加载时调用 `uni.setNavigationBarTitle()` 方法来设置标题：
    首先设置对应的语言包，并在入口文件参考以上说明通过 vue-i18n插件 进行语言包注册
   ```json
    // src/locale/custom/en.json
    {
        "home.title": "Home"
    }
   ```
    然后在页面加载时调用 `uni.setNavigationBarTitle()` 方法来设置标题。
   ```javascript
   // src/pages/index/index.vue
   onLoad() {
       uni.setNavigationBarTitle({
           title: this.$t('home.title')
       });
   }
   ```

2. **tabbar 动态设置内容**

   tabbar 不支持动态修改内容，但是可以通过自定义 tabbar 的方式，详情请参考[自定义 tabbar](https://uniapp.dcloud.net.cn/api/ui/tabbar.html#custom-tabbar)。

## 七. 语言 API 参考

### 框架内置 API

| API 名称                                                                             | 功能说明               |
| :----------------------------------------------------------------------------------- | :--------------------- |
| [uni.getLocale](https://uniapp.dcloud.net.cn/api/ui/locale.html#getlocale)           | 获取应用当前使用的语言 |
| [uni.setLocale](https://uniapp.dcloud.net.cn/api/ui/locale.html#setlocale)           | 设置应用语言           |
| [uni.onLocaleChange](https://uniapp.dcloud.net.cn/api/ui/locale.html#onlocalechange) | 监听应用语言变化       |

### Vue-i18n API

| API 名称               | 功能说明            |
| :--------------------- | :------------------ |
| `this.$i18n.locale`    | 获取或设置当前语言  |
| `this.$t(key)`         | 翻译指定 key 的文本 |
| `this.$tc(key, count)` | 复数形式翻译        |

### EM 组件库 API

| API 名称               | 功能说明                   |
| :--------------------- | :------------------------- |
| `Locale.use(lang)`     | 切换 EM 组件库语言         |
| `Locale.add(messages)` | 添加或扩展 EM 组件库语言包 |

## 八. 最佳实践

1. **统一语言 key 命名规范**：使用模块名+功能名的方式命名，如`home.title`、`user.login`
2. **将通用文案提取到 common 模块**：如"确认"、"取消"等通用按钮文本
3. **在入口文件中初始化语言**：优先使用系统语言，其次使用本地存储的语言
4. **封装统一的语言切换方法**：确保各部分语言同步切换
5. **定期检查语言文件完整性**：避免遗漏翻译或失效的 key

通过以上步骤，您可以在跨端框架中完整实现国际化功能，支持多语言切换和扩展。
