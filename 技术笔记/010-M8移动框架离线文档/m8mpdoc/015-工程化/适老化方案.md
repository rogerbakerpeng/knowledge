# M8.3 框架适老化方案

为了方便项目产品基于已有工程快速改造，提供此文档。

可基于已有工程，根据文档步骤快速改造应用。

## 原理

移动前端框架采用`rem`布局进行适老化调整：

`rem(root em)`是一个相对单位，基准是相对根节点字体大小。

比如，根节点设置`font-size=12px`，非根元素设置`width：2rem;`，那么非根元素的宽度转换成`px`就是`24px`。

将整个页面的元素样式单位转换成 rem，就可以通过根元素 html 的字体大小，控制整个页面的元素大小。

## 如何改造

1. 首先安装 postcss 插件：`npm i postcss-pxtorem@5.1.1 -S`;

2. 修改项目`postcss.config.js`, 在`plugins`中添加该插件，注意要在`@epoint-mrc/em-cli/lib/postcss-px-to-viewport`之前引入，参考：

```js
require('postcss-pxtorem')({
    rootValue: 16, // (Number | Function) 代表根元素字体大小或根据input参数返回根元素字体大小
    unitPrecision: 5, // （数字）允许 REM 单位增长到的十进制数字。
    propList: ['font-size'], // （数组）可以从 px 更改为 rem 的属性。
    selectorBlackList: [], //（数组）要忽略并保留为 px 的选择器
    replace: true, // （布尔值）替换包含 rems 的规则而不是添加回退。
    mediaQuery: false, // （布尔值）允许在媒体查询中转换 px。
    minPixelValue: 0 // （数字）设置要替换的最小像素值。
    // exclude: //（字符串，正则表达式，函数）要忽略并保留为 px 的文件路径。
});
```

3. 在入口文件`main.js`添加全局方法，用于设置基准值：

```js
// 获取当前基准值
Vue.prototype.$getRootFontSize = () => {
    let result = uni.getStorageSync('root_font_size');

    if (!result) {
        // 设置默认值
        Vue.prototype.$setRootFontSize('16px');

        return '16px';
    }

    return result;
};

// 设置当前基准值
Vue.prototype.$setRootFontSize = (value) => {
    uni.setStorageSync('root_font_size', value);
};
```

4. 在每个页面上添加`page-meta`节点设置页面根节点字体大小：

```html
<page-meta :root-font-size="$getRootFontSize()"></page-meta>
```

注意调用`$setRootFontSize`重置基准值时，需要刷新页面才会看到效果，在小程序中可以调用`uni.reLaunch`方法重新进入页面：

```js
// 重置基准值
this.$setRootFontSize('22px');
// 关闭其他页面，并重新打开页面
uni.reLaunch({
    url: 'index'
});
```
