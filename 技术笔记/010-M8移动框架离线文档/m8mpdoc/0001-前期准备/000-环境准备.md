## nodejs 环境安装

### 通过Node版本管理器安装

随着开发的进行，不同的项目中可能会有不同 nodejs 版本的要求，因此推荐使用 nvm 来安装和管理 nodejs。

#### windows

大部分人的操作系统是 Windows，而 Windows 下安装 nodejs 推荐使用 nvm 安装, nvm 可以便捷的安装多个版本的 nodejs 并支持快速切换当前使用的 nodejs 版本。

**安装 nvm**

可自行从 [https://github.com/coreybutler/nvm-windows](https://github.com/coreybutler/nvm-windows) 下载。

安装完成后可使用 nvm 来安装和管理 nodejs.

**设置国内下载镜像**

在 cmd 或者 powershell 中使用如下代码设置即可

```sh
nvm node_mirror  https://npmmirror.com/mirrors/node/
nvm npm_mirror https://npmmirror.com/mirrors/npm/
```

这样可以从国内地址开始下载，速度更快更稳定。

**安装特定版本的 nodejs**

对于 nodejs 的安装，正常情况下都是安装其 LTS 版本，也就是版本号首位是偶数的版本，如 22.x.x, 20.x.x, 18.x.x 等。

M8.4 框架中使用推荐的nodejs版本为 22.x.x，以安装 22.20.0 为例:

```sh
nvm install 22.20.0

# 查看已经安装的nodejs版本
nvm ls

# 切换并使用 nodejs 版本
nvm use xxx
```

#### Mac 和 Linux

mac 和 Linux 系统也可以使用 nvm 来安装 nodejs，你可以从此处 [https://github.com/nvm-sh/nvm](https://github.com/nvm-sh/nvm) 获取安装步骤和文件

在设置国内下载镜像时，mac 和 Linux 系统的设置方式和 windows 略有不同，这里使用的是环境变量，具体设置方式如下：

```sh
# 设置环境变量
export NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node
# 进行安装
nvm install 22.20.0
```

后续步骤和windows相同，在安装完成后参考 windows 的设置即可。

如果你是M系列设备，且需要使用 v16 以下版本的 nodejs, nvm 上的支持可能有问题，解决方案参考 [https://github.com/nvm-sh/nvm?tab=readme-ov-file#macos-troubleshooting](https://github.com/nvm-sh/nvm?tab=readme-ov-file#macos-troubleshooting)

### 直接安装 nodejs

如果你不涉及多个版本的 nodejs，也可以直接从 [https://nodejs.org/](https://nodejs.org/) 下载安装包双击进行安装，此操作各个系统基本均是一致的，不再展开描述。

注意需下载 LTS 的版本，如 22.x.x, 20.x.x, 18.x.x 等。

### nrm 安装

nrm 是一个可以管理和快速切换 npm 安装源的管理工具。 建议安装 nrm 来管理源，常用命令如下：

```sh
# 安装
npm install -g nrm  --registry=https://registry.npmmirror.com
# 查看可用
nrm ls
# 测试速度
nrm test
# 添加新的源
nrm add [名称] [地址]
# 切换源
nrm use [名称]
```

#### npm仓库

M8移动前端跨端框架使用的使用公司的私有化npm仓库，npm代码不暴露在公网上。

框架初始化npm install时，请确保网络处于公司内网，能够访问到[公司npm仓库](http://192.168.0.99:8081/nexus/)

#### 使用 pnpm

`pnpm` 是一款包管理工具，可以替代`npm`、`yarn`。对于开发来说，我们可以使用`pnpm`来安装依赖，提升重复安装依赖时的安装速度，提升开发效率。

##### 前置条件
由于 `pnpm` 安装对 `NodeJS` 有版本要求，同时 M8移动前端框架也对 `Nodejs` 有版本要求，所以使用 `pnpm` 需要注意以下前置条件：

- `pnpm` 版本指定为 `v7.13.2`;

- `NodeJS` 版本 >= `v14.6`;

##### 全局安装 `pnpm`：

```bash
npm install -g pnpm@7.13.2
```
::: endif

::: ifdef M84

### 安装 pnpm

pnpm 是一个新的包管理器，其可以在电脑上的一个位置安装依赖，在使用的地方使用软连接，从而大幅提升安装速度并节约本地磁盘的占用，具体可参阅 [pnpm](https://pnpm.io/zh/)

在已经具备node的环境下，直接将 pnpm 当作一个npm包安装即可：

```sh
# 安装 目前推荐使用 v10 版本
npm install -g pnpm@10
```

pnpm 的常规使用基本上和 npm 一样，将 npm 替换为 pnpm 即可，如：

```sh
# 运行定义好的 sctipts
pnpm run xxx
# 安装依赖
pnpm install xxx
# 安装依赖（作为开发环境的依赖）
pnpm install xxx -D
```
::: endif

##### 使用 `pnpm` 安装依赖：

在 M8移动前端框架工程目录下，使用 `pnpm install` 代替 `npm install` 安装依赖。

```bash
pnpm install
```

安装后，仍然可以继续使用 `npm` 进行项目开发，例如 `npm run dev`、`npm run build`。同时不影响`VScode 开发插件` 的使用。
