# Tag 标签

用于标记和选择。

## 基本用法

使用 `type` 属性来定义标签的类型。此外，`color` 属性可用于设置标签的背景颜色。

```html
<template>
  <e-tag-m>Tag 1</e-tag-m>
  <e-tag-m class="ml-2" type="success">Tag 2</e-tag-m>
  <e-tag-m class="ml-2" type="info">Tag 3</e-tag-m>
  <e-tag-m class="ml-2" type="warning">Tag 4</e-tag-m>
  <e-tag-m class="ml-2" type="danger">Tag 5</e-tag-m>
</template>
```

## 可移除标签

可以使用 `closable` 属性来定义一个可移除的标签。它接受一个布尔值。默认情况下，标签的移除具有淡入淡出的动画效果。如果您不想使用动画，可以将 `disable-transitions` 属性设置为 `true`。在标签被移除时触发 `close` 事件。

```html
<template>
  <e-tag-m v-for="tag in tags" :key="tag.name" class="mx-1" closable :type="tag.type">
    {{ tag.name }}
  </e-tag-m>
</template>

<script lang="ts" setup>
import { ref } from 'vue';

const tags = ref([
  { name: 'Tag 1', type: '' },
  { name: 'Tag 2', type: 'success' },
  { name: 'Tag 3', type: 'info' },
  { name: 'Tag 4', type: 'warning' },
  { name: 'Tag 5', type: 'danger' },
]);
</script>
```

## 动态编辑

您可以使用 `close` 事件来动态添加和删除标签。

```html
<template>
  <e-tag-m
    v-for="tag in dynamicTags"
    :key="tag"
    class="mx-1"
    closable
    :disable-transitions="false"
    @close="handleClose(tag)"
  >
    {{ tag }}
  </e-tag-m>
  <e-input-m
    v-if="inputVisible"
    ref="InputRef"
    v-model="inputValue"
    class="ml-1 w-20"
    size="small"
    @keyup.enter="handleInputConfirm"
    @blur="handleInputConfirm"
  />
  <e-button-m v-else class="button-new-tag ml-1" size="small" @click="showInput"> + New Tag </e-button-m>
</template>

<script lang="ts" setup>
import { nextTick, ref } from 'vue';
const inputValue = ref('');
const dynamicTags = ref(['Tag 1', 'Tag 2', 'Tag 3']);
const inputVisible = ref(false);
const InputRef = ref<InstanceType<typeof EpInput>>();

const handleClose = (tag: string) => {
  dynamicTags.value.splice(dynamicTags.value.indexOf(tag), 1);
};

const showInput = () => {
  inputVisible.value = true;
  nextTick(() => {
    InputRef.value!.input!.focus();
  });
};

const handleInputConfirm = () => {
  if (inputValue.value) {
    dynamicTags.value.push(inputValue.value);
  }
  inputVisible.value = false;
  inputValue.value = '';
};
</script>
```

## 大小

除了默认大小，标签组件还提供了三种额外的大小供您在不同场景中选择。

使用 `size` 属性设置额外的大小，可选值为 `large`、`default` 或 `small`。

```html
<template>
  <e-row-m>
    <e-tag-m class="mx-1" size="large">Large</e-tag-m>
    <e-tag-m class="mx-1">Default</e-tag-m>
    <e-tag-m class="mx-1" size="small">Small</e-tag-m>
  </e-row-m>

  <e-row-m class="mt-4">
    <e-tag-m class="mx-1" size="large" closable>Large</e-tag-m>
    <e-tag-m class="mx-1" closable>Default</e-tag-m>
    <e-tag-m class="mx-1" size="small" closable>Small</e-tag-m>
  </e-row-m>
</template>
```

## 主题

标签提供了三种不同的主题：`dark`、`light` 和 `plain`

使用 `effect` 来改变主题，默认为 `light`

```html
<template>
  <div class="tag-group my-2 flex flex-wrap gap-1 items-center">
    <span class="tag-group__title m-1 line-height-2">Dark</span>
    <e-tag-m v-for="item in items" :key="item.label" :type="item.type" class="mx-1" effect="dark">
      {{ item.label }}
    </e-tag-m>
    <e-tag-m v-for="item in items" :key="item.label" :type="item.type" class="mx-1" effect="dark" closable>
      {{ item.label }}
    </e-tag-m>
  </div>
  <div class="tag-group my-2 flex flex-wrap gap-1 items-center">
    <span class="tag-group__title m-1">Light</span>
    <e-tag-m v-for="item in items" :key="item.label" class="mx-1" :type="item.type" effect="light">
      {{ item.label }}
    </e-tag-m>
    <e-tag-m v-for="item in items" :key="item.label" class="mx-1" :type="item.type" effect="light" closable>
      {{ item.label }}
    </e-tag-m>
  </div>
  <div class="tag-group my-2 flex flex-wrap gap-1 items-center">
    <span class="tag-group__title m-1">Plain</span>
    <e-tag-m v-for="item in items" :key="item.label" class="mx-1" :type="item.type" effect="plain">
      {{ item.label }}
    </e-tag-m>
    <e-tag-m v-for="item in items" :key="item.label" class="mx-1" :type="item.type" effect="plain" closable>
      {{ item.label }}
    </e-tag-m>
  </div>
</template>

<script lang="ts" setup>
import { ref } from 'vue';

import type { TagProps } from '@epoint-mfe/eui-components';

type Item = { type: TagProps['type']; label: string };

const items = ref<Array<Item>>([
  { type: '', label: 'Tag 1' },
  { type: 'success', label: 'Tag 2' },
  { type: 'info', label: 'Tag 3' },
  { type: 'danger', label: 'Tag 4' },
  { type: 'warning', label: 'Tag 5' }
]);
</script>
```

```html
  </div>
  <div class="flex flex-wrap gap-2 my-2">
    <e-tag-m v-for="item in items" :key="item.label" :type="item.type" class="mx-1" effect="plain" round>
      {{ item.label }}

```

## 图标标签

标签可以添加图标，使其更加醒目。

使用 `icon` 属性为标签添加图标。您可以在我们的 `Icon` 组件中找到所需图标。

```html
<template>
  <div class="flex flex-wrap gap-2 my-2">
    <e-tag-m :icon="User">User</e-tag-m>
    <e-tag-m :icon="Star" type="success">Star</e-tag-m>
    <e-tag-m :icon="Message" type="info">Message</e-tag-m>
    <e-tag-m :icon="Warning" type="warning">Warning</e-tag-m>
    <e-tag-m :icon="Delete" type="danger">Delete</e-tag-m>
  </div>
  <div class="flex flex-wrap gap-2 my-2">
    <e-tag-m :icon="User" effect="dark">User</e-tag-m>
    <e-tag-m :icon="Star" type="success" effect="dark">Star</e-tag-m>
    <e-tag-m :icon="Message" type="info" effect="dark">Message</e-tag-m>
    <e-tag-m :icon="Warning" type="warning" effect="dark">Warning</e-tag-m>
    <e-tag-m :icon="Delete" type="danger" effect="dark">Delete</e-tag-m>
  </div>
  <div class="flex flex-wrap gap-2 my-2">
    <e-tag-m :icon="User" round>User</e-tag>
    <e-tag-m :icon="Star" type="success" round>Star</e-tag-m>
    <e-tag-m :icon="Message" type="info" round>Message</e-tag-m>
    <e-tag-m :icon="Warning" type="warning" round>Warning</e-tag-m>
    <e-tag-m :icon="Delete" type="danger" round>Delete</e-tag-m>
  </div>
</template>

<script lang="ts" setup>
import { Delete, Message, Star, User, Warning } from '@epoint-mfe/eui-icons';
</script>
```

## 可选标签

有时因业务需求，我们可能需要类似于复选框的标签，但是**按钮式复选框**无法满足我们的需求，这时就有了 `check-tag`

基本的 check-tag 使用，API 非常简单。通过 `checked` 属性控制选中状态，通过 `disabled` 属性控制禁用状态。

```html
<template>
  <div>
    <e-check-tag-m checked style="margin-right: 8px">Checked</e-check-tag-m>
    <e-check-tag-m :checked="checked" @change="onChange">Toggle me</e-check-tag-m>
  </div>
</template>

<script lang="ts" setup>
import { ref } from 'vue';

const checked = ref(false);

const onChange = (status: boolean) => {
  checked.value = status;
};
</script>
```

## Tag API

### Tag Attributes

| 属性                | 描述                   | 类型                   | 默认值 |
| :------------------ | :--------------------- | :--------------------- | :----- |
| type                | 标签的类型             | `enum`-`'success' \| 'info' \| 'warning' \| 'danger' \| ''`                 | ''     |
| closable            | 是否可以移除标签       | `boolean`              | false  |
| disable-transitions | 是否禁用动画           | `boolean`              | false  |
| hit                 | 标签是否具有突出的边框 | `boolean`              | false  |
| color               | 标签的背景颜色         | `string`               | ''     |
| size                | 标签的大小             | `enum`-`'large' \| 'default' \| 'small' \| ''`                 | ''     |
| effect              | 标签的主题             | `enum`-`'dark' \| 'light'\| 'plain'`                 | light  |
| round               | 标签是否是圆角的       | `boolean`              | false  |
| icon                | 图标组件               | `string` / `Component` | —      |

### Tag Events

| 名称  | 描述           | 类型       |
| :---- | :------------- | :--------- |
| click | 点击标签时触发 | `Function`-`(evt: TouchEvents) => void` |
| close | 移除标签时触发 | `Function`-`(evt: TouchEvents) => void` |

### Tag Slots

| 名称 | 描述           |
| :--- | :------------- |
| default | 自定义默认内容 |

## CheckTag API

### CheckTag Attributes

| 名称                      | 描述     | 类型      | 默认值 |
| :------------------------ | :------- | :-------- | :----- |
| checked / v-model:checked | 是否选中 | `boolean` | false  |
| disabled                  | 是否禁用 | `boolean` | false  |

### CheckTag Events

| 名称   | 描述                  | 类型       |
| :----- | :-------------------- | :--------- |
| change | 点击 Check Tag 时触发 | `Function`-`(value: boolean) => void` |

### CheckTag Slots

| 名称    | 描述           |
| :------ | :------------- |
| default | 自定义默认内容 |
