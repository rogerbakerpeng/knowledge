# EUI4.0 移动端组件库 介绍

## 介绍

**EUI4.0 移动端组件库** 是基于 **M8.4 移动前端框架** 跨端 UI 组件库。`M8.4.4`版本之后支持.

设计规范使用 [EUI4.0 设计规范](https://www.figma.com/design/B6xrs3nOclNE3SGumxeoxF/2025EUI4.0%E6%8D%A2%E8%82%A4)；

组件参数、事件、插槽等均与 [PC Vue3 框架 EUI4.0 组件库](http://192.168.219.170/docs/vue/latest/component/guide/introduction.html)规范趋同；

---

## 目标

EUI4.0 移动端组件库 旨在为公司后台开发者提供一套与 PC Vue3 框架 EUI4.0 趋同的，高效、灵活的组件解决方案，帮助快速构建移动应用。

同时，由于我们组件库的参数、事件、插槽等均与 PC Vue3 框架 EUI4.0 组件库规范趋同，因此开发者可以更轻松地在移动端和 PC 端之间进行代码复用和迁移。

### 移动端组件与 PC 使用差异：

- 将 PC 端组件 `<e-xx>` 替换为移动端组件 `<e-xx-m>`

- 将 PC 端组件 `<ep-xx>` 替换为移动端组件 `<ep-xx-m>`

- 将 PC 端 import 的路径中的 `@epoint-fe/eui-components` 替换为 `@epoint-mfe/eui-components`

- `@epoint-mfe/eui-components` 导出的相关 API 使用移动端版本

- 移动端组件的样式和交互方式可能与 PC 端有所不同，开发者需要根据实际移动端组件文档进行调整。

### PC 端代码示例：

```html
<template>
    <e-form label-width="120px">
        <e-form-item label="手机号">
            <ep-input v-model="input" placeholder="Please input" :desensitization-type="DESENDATATYPE_MOBILE_PHONE" />
        </e-form-item>

        <e-form-item label="身份证号">
            <ep-input v-model="input2" placeholder="Please input" desensitization-type="ID_CARD" />
        </e-form-item>

        <e-button type="primary" @click="getInputValue">获取输入值</e-button>
    </e-form>
</template>

<script lang="ts" setup>
    import { ref } from 'vue';
    import { DESENDATATYPE_MOBILE_PHONE, EMessage } from '@epoint-fe/eui-components';

    const input = ref('17215683972');
    const input2 = ref('612300190001010000');

    const getInputValue = () => {
        EMessage.success(`手机号:${input.value}`);
        EMessage.success(`身份证号:${input2.value}`);
    };
</script>
```

### 移动端代码示例：

```html
<template>
    <e-form-m>
        <e-form-item-m label="手机号">
            <ep-input-m v-model="input" placeholder="Please input" :desensitization-type="DESENDATATYPE_MOBILE_PHONE" />
        </e-form-item-m>

        <e-form-item-m label="身份证号">
            <ep-input-m v-model="input2" placeholder="Please input" desensitization-type="ID_CARD" />
        </e-form-item-m>

        <e-button-m type="primary" @click="getInputValue">获取输入值</e-button-m>
    </e-form-m>
</template>

<script lang="ts" setup>
    import { ref } from 'vue';
    import { DESENDATATYPE_MOBILE_PHONE, EMessageM } from '@epoint-mfe/eui-components';

    const input = ref('17215683972');
    const input2 = ref('612300190001010000');

    const getInputValue = () => {
        EMessageM.success(`手机号:${input.value}`);
        EMessageM.success(`身份证号:${input2.value}`);
    };
</script>
```
