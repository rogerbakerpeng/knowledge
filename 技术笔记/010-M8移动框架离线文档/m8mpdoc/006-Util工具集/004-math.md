# Util.math

## 说明

计算机编程语言里浮点数计算会存在精度丢失问题（或称舍入误差），其根本原因是二进制和实现位数限制有些数无法有限表示。

例如：

```
0.1 + 0.2 == 0.30000000000000004
0.2 + 0.4 == 0.6000000000000001
0.1 * 0.2 == 0.020000000000000004
```

## 使用场景

- 使用此方法可规避以上出现浮点数加减乘除精度丢失的问题

## 方法说明

注：此工具集下的方法以 `Util.math` 为前缀进行调用

### add(number1, number2)

浮点数相加

**平台差异**

|  H5   | 新点小程序 | 微信小程序 | 支付宝小程序 |
| :---: | :--------: | :--------: | :----------: |
|   √   |     √      |     √      |      √       |

**示例**

```js
Util.math.add(0.1, 0,2);  // 0.3
```
