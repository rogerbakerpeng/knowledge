# Util.storage

## 使用场景

应用中用到数据存储的地方

## 方法说明

注：此工具集下的方法以 `Util.storage` 为前缀进行调用

H5、新点小程序端为`localStorage`，浏览器限制5M大小，是缓存概念，可能会被清理;

微信、支付宝小程序端为其自带的`storage` api，数据存储生命周期跟小程序本身一致，即除用户主动删除或超过一定时间被自动清理，否则数据都一直可用;

微信小程序单个 key 允许存储的最大数据长度为 1MB，所有数据存储上限为 10MB;

支付宝小程序单条数据转换成字符串后，字符串长度最大200*1024。同一个支付宝用户，同一个小程序缓存总上限为10MB;

### setItem(key, value)

存储键值对

存储的value如果为对象类型，默认均会尝试转成JSON字符串进行存储

**平台差异**

|  H5   | 新点小程序 | 微信小程序 | 支付宝小程序 |
| :---: | :--------: | :--------: | :----------: |
|   √   |     √      |     √      |      √       |

**示例**

```js
Util.storage.setItem('key1', '{"1":"2"}');
```

### getItem(key, isJson)

读取键值对，可以控制是否自动转为JSONObject对象

返回的内容默认均为字符串类型

**平台差异**

|  H5   | 新点小程序 | 微信小程序 | 支付宝小程序 |
| :---: | :--------: | :--------: | :----------: |
|   √   |     √      |     √      |      √       |

__参数说明__

| 参数 | 参数类型 | 说明 |
| --- | --- | --- |
| isJson | Boolean | 是否自动转为`JSONObject`对象，如果为`true`，会尝试自动转换，如果转换失败，则返回原来的字符串 |

**示例**

```js
// {1: "2"}
Util.storage.getItem('key1');

// Object {1: "2"}
Util.storage.getItem('key1', true);
```

### each(callback, options)

遍历键值对

**平台差异**

|  H5   | 新点小程序 | 微信小程序 | 支付宝小程序 |
| :---: | :--------: | :--------: | :----------: |
|   √   |     √      |     √      |      √       |

__options配置说明__

| 参数 | 参数类型 | 说明 |
| --- | --- | --- |
| isJson | Boolean | 是否自动转为`JSONObject`对象，如果为`true`，会尝试自动转换，如果转换失败，则返回原来的字符串 |
| include | RegExp或Array[RegExp] | 需要过滤的正则表达式或数组，如果不传默认为所有都可以 |
| exclude | RegExp或Array[RegExp] | 需要排除的正则表达式或数组，如果不传默认为不排除 |

**示例**

```js
Util.storage.each(function(key, value) {
    console.log(key + ':' + value);
},
{
    isJson: false,
    // 只允许 key开头的键
    include: /^key/,
    // 排除 a开头的键
    exclude: /^a/
});
```
