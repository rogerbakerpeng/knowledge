# Util.base64

## 使用场景

- `base64` 需要转换成 `blob` 对象

- `blob` 对象转换成 `base64`

- 获取 `base64` 的 `mime` 类型

- 获取 `base64` 的 `url` 部分

- 获取 `base64` 去除 `url` 部分

- 注意在小程序（微信、支付宝）中使用，不存在 `blob` 对象，需要使用`ArrayBuffer`替代

## 方法说明

注：此工具集下的方法以 `Util.base64` 为前缀进行调用

### base64ToBlob(base64)

将 `base64` 转换成 `blob` 对象

**平台差异**

|  H5   | 新点小程序 | 微信小程序 | 支付宝小程序 |
| :---: | :--------: | :--------: | :----------: |
|   √   |     √      |     x      |      x       |

**示例**
```js
// 返回转换完成后的 blob 对象
Util.base64.base64ToBlob(base64);
```

### blobToBase64(file, callback)

将 `blob` 对象转换成 `base64`

**平台差异**

|  H5   | 新点小程序 | 微信小程序 | 支付宝小程序 |
| :---: | :--------: | :--------: | :----------: |
|   √   |     √      |     x      |      x       |

__参数说明__

| 参数     | 参数类型 | 说明                                |
| -------- | -------- | ----------------------------------- |
| file     | Blob     | `必选` 文件对象                     |
| callback | Function | `必须` 返回转换完成后的 `base64` 值 |

**示例**
```js
Util.base64.blobToBase64(file, b64 => {
  // 这里获取到转换完成后的 base64 值
});
```
