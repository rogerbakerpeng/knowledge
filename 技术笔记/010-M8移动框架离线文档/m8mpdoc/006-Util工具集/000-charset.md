# Util.charset

## 使用场景

- 需要用到 `UTF-16`，`UTF-8` 编码转换的地方

- 需要用到 `Base64-UTF-16`，`Base64-UTF-8` 编码解码的地方

- 可以通过在线工具测试 [BASE64方式加密、解密](https://www.sojson.com/base64.html)

## 方法说明

注：此工具集下的方法以 `Util.charset` 为前缀进行调用

### strToBinary(str)

将字符串转为二进制字符串

**平台差异**

|   √   |     √      |     √      |      √       |

**示例**

```js
const str = '你好，世界！';

// 10011110110000010110010111110111111111000011001001110000101101110101010011001111111100000001
Util.charset.strToBinary(str);
```

### base64.encode(str, type, isUri)

将目标字符串进行 `Base64` 编码

**平台差异**

|  H5   | 新点小程序 | 微信小程序 | 支付宝小程序 |
| :---: | :--------: | :--------: | :----------: |
|   √   |     √      |     √      |      √       |

__参数说明__

| 参数 | 参数类型 | 说明 |
| --- | ---- | --- |
| str | String | 目标字符串，只支持 `UTF-16` 编码形式，可以认为，`JS` 中默认的输入就是 `UTF-16` 形式 |
| type | String | 类别，可选 `utf8`、`utf16`，默认为 `utf8`。`utf8`代表先转为 `UTF-8` 编码然后再进行 `Base64` 编码 |
| isUri | Boolean | 是否进行 `uri` 编码，如果为 `true`，结果中一些特殊字符会进行 `uri` 编码（如 `=` 号） |

**示例**

```js
var str = '你好，世界！';

// 5L2g5aW977yM5LiW55WM77yB
Util.charset.base64.encode(str);

// 5L2g5aW977yM5LiW55WM77yBPT0%3D
Util.charset.base64.encode('你好，世界！==', 'utf8', true);
```

### base64.deocde(str, type, isUri)

将 `Base64` 编码的字符串解码

**平台差异**

|  H5   | 新点小程序 | 微信小程序 | 支付宝小程序 |
| :---: | :--------: | :--------: | :----------: |
|   √   |     √      |     √      |      √       |

__参数说明__

| 参数 | 参数类型 | 说明 |
| --- | ---- | --- |
| str | String | 目标字符串，只支持 `Base64` 编码后的字符串 |
| type | String | 类别，可选 `utf8`，`utf16`，默认为 `utf8`。`utf8`代表先解码，然后将结果从 `UTF-8` 编码转换为 `UTF-16` 编码 |
| isUri | Boolean | 是否进行 `uri` 编码，如果为 `true`，在编码前，会对特殊字符会进行 `uri` 解码(如 `=` 号) |

**示例**

```js
// 你好，世界！
Util.charset.base64.decode('5L2g5aW977yM5LiW55WM77yB');

// 你好，世界！==
Util.charset.base64.decode('5L2g5aW977yM5LiW55WM77yBPT0%3D', 'utf8', true);
```
