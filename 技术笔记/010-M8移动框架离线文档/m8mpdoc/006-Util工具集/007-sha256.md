# Util.sha256

## 使用场景

- 服务端存储的是 `sha256` 散列过后的密码，此时客户端也需要用 `sha256` 对密码进行处理

- 可以通过在线工具测试[在线加密解密(采用Crypto-JS实现)](http://tool.oschina.net/encrypt?type=2)

## 方法说明

注：此工具集下的方法以 `Util.sha256` 为前缀进行调用

#### hex(str)

将目标字符串进行 `sha256` 散列，并且返回小写形式的`16进制字符串`

**平台差异**

|  H5   | 新点小程序 | 微信小程序 | 支付宝小程序 |
| :---: | :--------: | :--------: | :----------: |
|   √   |     √      |     √      |      √       |

__参数说明__

| 参数 | 参数类型 | 说明 |
| --- | --- | --- |
| str | String | 目标字符串，只支持`UTF-16`编码形式，可以认为，`JS`中默认的输入就是`UTF-16`形式 |

**示例**

```js
const str = '我的密码是:abcd123';

// 59858ba03b7b2eca0673bd55f2c8685b8782a0f57bec12f8082aa9934cddcb51
Util.sha256.hex(str);
```
