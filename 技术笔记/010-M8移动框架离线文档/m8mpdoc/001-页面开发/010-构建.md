# 构建

移动前端跨端框架目前支持的构建环境：

-   H5

-   H5-EJS

-   H5-钉钉

-   微信小程序

-   支付宝小程序

-   新点小程序 (>= 8.3.2)

## 构建资源位置

移动前端跨端框架构建后的资源在`dist/build`文件夹下

其中 H5、H5-EJS、H5-钉钉、新点小程序 构建后的资源都在 `dist/build/h5` 下

微信小程序 构建后的资源在 `dist/build/mp-weixin` 下

支付宝小程序 构建后的资源在 `dist/build/mp-alipay` 下

微信小程序、支付宝小程序构建后需要通过微信、支付宝小程序开发者工具，导入对应的构建资源，进行上架预览等操作。

## 构建命令

### H5:

```bash
npm run build
```

是否需要 jssdk 环境相关 API，在 config.js 中通过 env 函数控制：

```js
/**
* 开发环境常量，ejs、dingtalk
*/
env: (function () {
    // var ENV_H5 = 'uni';
    // var ENV_EJS = 'native';
    // var ENV_DD = 'dd';
    var ENV_EJS_H5 = 'native_uni';
    // var ENV_DD_H5 = 'dd_uni';
    // var ENV_ALL = 'native_dd_uni';

    return ENV_EJS_H5;
})(),
```
此处的`uni`表示`uni-app`提供的h5相关API，所以`uni`可以理解为以往的`h5`含义。

框架根据env函数返回的字符串加载指定的jssdk，例如:

`'native_uni'`加载ejs.native和uni.h5的jssdk

`'native_dd_uni'`加载ejs.native、dd和uni.h5的jssdk

### 微信小程序:

微信小程序 构建命令：

```bash
npm run build:mp-weixin
```

### 支付宝小程序:

支付宝小程序 构建命令：

```bash
npm run build:mp-alipay
```

### EJS-新点小程序

(>= v8.3.2)

EJS-新点小程序 构建命令：

```bash
npm run build -- --moduleType=mp-epoint --moduleName=m8demo --buildType=build
```

参数描述：

|属性|必填|描述|默认|
|:-|:-|:-|:-|:-|
|moduleType|否|当前构建类型，可选：mp-epoint、mp-epoint-card、h5|h5|
|moduleName|否|构建模块名称||
|buildType|否|新点小程序构建类型，可选：build、debug、upload||
