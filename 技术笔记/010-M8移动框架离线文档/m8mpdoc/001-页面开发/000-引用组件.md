# 引用组件

传统vue项目开发，引用组件需要`导入 - 注册 - 使用`三个步骤，如下：

```js
<template>
    <view>
        <!-- 3.使用组件 -->
        <em-cell title="1"></em-cell>
    </view>    
</template>
<script>
    // 1.导入组件
    import emCell from '@components/em-cell/em-cell.vue'
    export default {
        components:{emCell} // 2.注册组件
    }
</script>
```
`M8`的`easycom`机制，将组件引用进一步优化，开发者只管使用，无需考虑导入和注册，更为高效：

```js
<template>
    <view>
        <!-- 1.直接使用组件 -->
        <em-cell title="1"></em-cell>
    </view>    
</template>
<script>
   
</script>
```

在 `M8` 项目中，页面引用组件和组件引用组件的方式都是一样的（可以理解为：页面是一种特殊的组件），均支持通过 `easycom` 方式直接引用。
