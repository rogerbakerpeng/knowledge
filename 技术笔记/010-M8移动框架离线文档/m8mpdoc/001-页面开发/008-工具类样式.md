# 工具类样式

## 说明

`M8` 跨端框架中集成了 `M7` 中的工具类样式，并且还提供了其他工具类样式

[M7 工具类样式地址](https://fe.epoint.com.cn/m7fedoc/index/index.php#page=util_style_class)

## 扩展内置样式说明

M8 跨端框架提供了一批内置的样式变量，方便开发者使用。

### 内置 CSS 变量

| CSS 变量            | 描述                   | App                                                                                                                 | 平台小程序 | H5                   |
| :------------------ | :--------------------- | :------------------------------------------------------------------------------------------------------------------ | :----- | :------------------- |
| --status-bar-height | 系统状态栏高度         | [系统状态栏高度](http://www.html5plus.org/doc/zh_cn/navigator.html#plus.navigator.getStatusbarHeight)，其他注意见下 | 25px   | 0                    |
| --window-top        | 内容区域距离顶部的距离 | 0                                                                                                                   | 0      | NavigationBar 的高度 |
| --window-bottom     | 内容区域距离底部的距离 | 0                                                                                                                   | 0      | TabBar 的高度        |

**注意：**

-   `var(--status-bar-height)` 此变量在微信小程序环境为固定 `25px`。
-   当设置 `"navigationStyle":"custom"` 取消原生导航栏后，由于窗体为沉浸式，占据了状态栏位置。此时可以使用一个高度为 `var(--status-bar-height)` 的 view 放在页面顶部，避免页面内容出现在状态栏。
-   由于在 H5 端，不存在原生导航栏和 tabbar，也是前端 div 模拟。如果设置了一个固定位置的居底 view，在平台小程序端是在 tabbar 上方，但在 H5 端会与 tabbar 重叠。此时可使用`--window-bottom`，不管在哪个端，都是固定在 tabbar 上方。

**代码块**

示例 1 - 普通页面使用 css 变量：

```html
<template>
    <page-meta>
        <navigation-bar />
    </page-meta>
    <view>
        <view class="status_bar">
            <!-- 这里是状态栏 -->
        </view>
        <view>状态栏下的文字</view>
    </view>
</template>
<style>
    .status_bar {
        height: var(--status-bar-height);
        width: 100%;
    }
</style>
```

```html
<template>
    <view>
        <view class="toTop">
            <!-- 这里可以放一个向上箭头，它距离底部tabbar上浮10px-->
        </view>
    </view>
</template>
<style>
    .toTop {
        bottom: calc(var(--window-bottom) + 10px);
    }
</style>
```

示例 2 - 页面获取状态栏高度

```html
<template>
    <view class="content">
        <view :style="{ height: iStatusBarHeight + 'px'}"></view>
    </view>
</template>

<script>
    export default {
        data() {
            return {
                iStatusBarHeight: 0
            };
        },
        onLoad() {
            this.iStatusBarHeight = uni.getSystemInfoSync().statusBarHeight;
        }
    };
</script>
```

### uni.scss 全局变量

M8 跨端框架中的 `uni.scss` 文件，默认全局引用，其中默认配置了一批 css 变量，这些变量可以在 css 代码中直接使用。我们的跨端组件库也都使用了这些变量，开发者也可以在文件中添加自己需要的全局变量。具体内容请查看框架中的 `src/uni.scss`文件。
