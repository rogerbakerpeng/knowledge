# 路径别名

## 说明

为了方便开发人员，快速通过 `import` 引入资源，而无需去一层层查找资源路径，故 `M8` 跨端框架对各个目录设置了别名，方便快速引用

| 别名               | 对应路径                                                     |
| ------------------ | ------------------------------------------------------------ |
| @                  | src                                                          |
| @utils             | node_modules/@epoint-mrc/utils/dist/utils.h5(或者 mp).min.js |
| @components        | node_modules/@epoint-mrc/em-components/src/components        |
| @components_custom | src/components/custom_components                             |
| @common            | src/common                                                   |
| @static            | src/static                                                   |
| @shared            | src/shared                                                   |
| @public            | public                                                       |
| @boot              | src/shared/boot.js                                           |
| @build             | build                                                        |
| @mock              | build/resolution/mock/index.js                               |

**注意：比如要引入 `Mock`，直接写为 `@mock` 即可**
