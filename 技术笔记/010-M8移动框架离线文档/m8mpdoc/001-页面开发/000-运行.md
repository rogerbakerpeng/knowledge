# 运行

## 前置条件

已经根据上述文档搭建好开发环境


###  第一步：导入项目

打开开发模板：打开`VSCode`，选择“文件 > 打开文件夹”，选择框架所在的文件夹打开。

![](https://fdoc.epoint.com.cn/onlinedoc/rest/frame/base/attach/attachAction/getContent?isCommondto=true&attachGuid=1478d4c0-8f5d-4143-a183-3f760ab1485d)

###  第二步: 初始化

因开发包在本地运行需要依赖一些文件，需要先下载这些文件并安装。

通过在项目根目录执行如下命令安装依赖包。

```js
npm install
```

###  第三步: 运行

```shell
npm run dev:%PLATFORM% // 本地调式
```

``%PLATFORM%`` 可取值如下：

|值|平台|
|---|---|
|h5|H5|
|mp-alipay|支付宝小程序|
|mp-weixin|微信小程序|


* 对应不同平台会在dist文件夹下生成对应平台包，可使用对应平台的开发工具打开（如微信开发者工具）。

（>= 8.3.2）支持 H5 平台 预览时自动打开指定模块：

```
npm run dev -- --moduleName=m8demo
```

### 第四步： 预览
构建成功后会自动启动浏览器预览。

pages.json中pages对象下的第一个路径为应用默认加载页面，可以通过模块下的router.js配置[isFirstModule](http://app.epoint.com.cn/m8mpdoc/?file=011-vuex%E4%B8%8Erouter%E7%9A%84%E4%BD%BF%E7%94%A8/router%E7%9A%84%E4%BD%BF%E7%94%A8#router.js%20%E6%94%AF%E6%8C%81%E9%85%8D%E7%BD%AE)指定首页模块。
