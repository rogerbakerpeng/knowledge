# 个性化框架组件

个性化组件可以基于框架的跨端组件二次封装，这样方便后续更新框架组件，以及对框架组件进行异步分包。

以下以个性化 tag 组件为例:

1、在`src\components\custom_components`目录下新建个性化组件目录 `gxh-tag`，在该组件目录下新建`gxh-tag.vue`文件。

2、个性化时，对于不需要改动的属性，可以直接传给框架的`em-tag`组件，针对需要个性化的部分进行个性化修改。注意，微信、支付宝小程序限制禁止使用`v-bind="$props"`和`v-on="$listeners"`，需要将原有组件所有属性和事件都需要保留传递。示例代码：

```html
<em-tag
    :size="size"
    :mark="mark"
    :color="color"
    :plain="plain"
    :round="round"
    :textColor="textColor"
    :closeable="closeable"
    :type="type"
    :basicType="basicType"
    :photo="photo"
    :status="status"
    @click="onClick"
    @close="onClose"
>
    <!-- 这里个性化添加一个icon -->
    <em-icon :name="name"></em-icon>
    <slot></slot>
</em-tag>
```

```js
import emTag from '@epoint-mrc/em-components/src/components/em-tag/em-tag.vue';
export default {
    // 通过extends继承框架组件
    extends: emTag,
    props: {
        name: {
            type: String,
            default: 'plus'
        }
    }
};
```

3、个性化完成后，在页面中引入使用：

```html
<div class="content">
    <gxh-tag type="success">标签</gxh-tag>
</div>
```

```js
import gxhTag from '@components_custom/gxh-tag/gxh-tag.vue';
export default {
    components: {
        gxhTag
    }
};
```
或者也可以通过easycom自动引入：

- 在`src/pages.json`文件的`easycom`字段中添加对个性化组件的引入正则：

```json
{
    "easycom": {
        "autoscan": true,
        "custom": {
            "^uni-(.*)": "@dcloudio/uni-ui/lib/uni-$1/uni-$1.vue",
            "^em-(chart)": "@epoint-mrc/em-components/src/sub_components/em-$1/em-$1.vue",
            "^em-(.*)": "@epoint-mrc/em-components/src/components/em-$1/em-$1.vue",
            "^gxh-(.*)": "@/components/custom_components/gxh-$1/gxh-$1.vue" // 个性化组件引入的匹配规则
        }
    }
}
```

- 然后就可以直接在页面中使用以`gxh-`为前缀的个性化组件，不需要手动引入：

```html
<div class="content">
    <gxh-tag type="success">标签</gxh-tag>
</div>
```
