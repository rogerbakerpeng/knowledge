# M8 安全适配区域匹配

## 背景：

因各版本型号的手机均在项目上出现不同情况下安全区域被遮挡等问题，为统一处理，现提供以下代码进行处理。

## vue 示例相关代码

<font color="red">iphone 机型可以通过 ios 提供的新特性进行适配，而安卓生态百花齐放，也没有安全适配区的一个概念，机型涉及刘海屏、水滴屏、全面屏等，所以对于它的适配，在ejs容器中采用 JSBridge 方案，在小程序中使用uniapp提供的--status-bar-height变量</font>

```html
<!-- html部分 -->
<template>
    <div
        :style="{ '--statusBarHeight': statusBarHeight + 'px' }"
        :class="['container', isIos ? 'ioswrap' : 'androidwrap']"
    >
        <div class="header" id="header">顶部的安全适配区</div>
        <div class="main2" id="main">
            <div v-for="item in 50" :key="item">{{ item }}</div>
        </div>
        <div class="footer" id="footer">底部的安全适配区</div>
    </div>
</template>

<!-- js部分 -->
<script>
    export default {
        name: 'List',
        // 定义用到的数据，在template中使用{{ }}包裹，自动实现绑定
        data() {
            return {
                isIos: ejs.os.ios,
                statusBarHeight: '0px'
            };
        },
        // 实例创建完成后调用
        created() {
            let that = this;

            // #ifdef H5
            if (ejs.os.ejs) {
                // ejs环境获取真实状态栏高度
                ejs.device.getDeviceInfo({
                    success: function (result) {
                        that.statusBarHeight = result.statusBarHeight;
                    },
                    error: function (error) {
                        ejs.ui.alert(JSON.stringify(error));
                    }
                });
            }
            // #endif
        },
        // 实例DOM被挂载后调用
        mounted() {
            // #ifdef H5
            if (ejs.os.ejs) {
                ejs.navigator.hide({
                    success: function (result) {},
                    error: function (error) {}
                });
            }
            // #endif
        }
    };
</script>

<!-- css部分 -->
<style lang="scss" scoped>
    $safe-top: 50px;
    $safe-bottom: 50px;

    /* 适配 iphone 底部安全区 */
    .safe-area-inset-top {
        /* iOS 11.2 以下机型 */
        padding-top: constant(safe-area-inset-top);
        /* iOS 11.2 以上机型*/
        padding-top: env(safe-area-inset-top);
    }

    .safe-area-inset-bottom {
        padding-bottom: constant(safe-area-inset-bottom);
        padding-bottom: env(safe-area-inset-bottom);
    }

    .ioswrap {
        .header {
            @extend .safe-area-inset-top;
            position: fixed;
            top: 0;
            left: 0;
            z-index: 100;
            width: 100%;
            display: flex;
            align-items: center;
            justify-content: center;
            height: $safe-top;
            background-color: #f5f6f7;
        }

        .footer {
            @extend .safe-area-inset-bottom;
            position: fixed;
            bottom: 0;
            left: 0;
            z-index: 100;
            width: 100%;
            display: flex;
            align-items: center;
            justify-content: center;
            width: 100%;
            height: $safe-bottom;
            background-color: #f5f6f7;
        }
    }

    .androidwrap {
        .header {
            position: fixed;
            top: 0;
            left: 0;
            z-index: 100;
            width: 100%;
            display: flex;
            align-items: center;
            justify-content: center;
            height: $safe-top;
            background-color: #f5f6f7;
            // #ifdef H5
            padding-top: var(--statusBarHeight);
            // #endif
            // #ifndef H5
            padding-top: var(--status-bar-height);
            // #endif
        }

        .footer {
            position: fixed;
            bottom: 0;
            left: 0;
            z-index: 100;
            width: 100%;
            display: flex;
            align-items: center;
            justify-content: center;
            width: 100%;
            height: $safe-bottom;
            background-color: #f5f6f7;
        }
    }
</style>
```
