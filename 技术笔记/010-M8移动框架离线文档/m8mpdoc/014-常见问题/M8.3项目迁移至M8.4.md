# M8.3 项目迁移 M8.4 指南

M8.4 框架相比 M8.3，由 `webpack + vue2 + vuex` 升级为 `vite + vue3 + ts + pinia`，对于业务代码来说，最主要的变化就是语法上面的变化。

## Vue 非兼容性语法调整

Vue3 支持选项式和组合式两种 API 风格书写，但仍有一些特性发生了变化，必须根据新变化做出对应修改。

[Vue3 迁移指南](https://v3-migration.vuejs.org/zh/breaking-changes/)中已经列出所有非兼容性改变，并详细解释了改变的理由，提供了迁移策略，请逐一对照进行调整。

## 框架部分调整

#### 1. 状态管理调整

`M8.4` 使用`pinia`进行状态管理，使用方式上与`vuex`有些区别，具体使用方式请参考框架文档[Pinia 的使用](/m8mpdoc/?file=015-工程化/Pinia的使用)进行调整。

#### 2. 只支持使用 `ES6` 模块规范

`vite`基于`ESM`，业务代码也应遵循 `ESM` 的导入导出规范。

##### 1）如果项目中存在`CommonJS`规范的导入导出需要进行调整：

`CommonJS`：

```js
// 导入
const obj = require('./test.js');

// 导出
const obj = { a: 1 };
module.exports = obj;
```

需要改为`ESM`:

```js
// 导入
import obj from './test.js';

// 导出
export default { a: 1 };
```

##### 2）如果项目仅仅用到了`require`引入资源，有几种解决方案：

-   一是手动改为 `import` 引入资源;

-   二是安装转换插件`vite-plugin-require-transform`，自动将`require`语句转为`import`语句：

```js
// 首先安装该插件
npm i vite-plugin-require-transform -D

// 然后在根目录vite.config.ts文件中添加该插件
import requireTransform from 'vite-plugin-require-transform';

const plugins = [
    ...
    requireTransform({
        fileRegex: /.ts$|.tsx$|.vue$|.js$/
    })
];

export default defineConfig({
    plugins,
    ...
});
```

-   第三种改为使用 `vite` 语法获取静态资源，该方法只支持 H5 端。官方文档说明：[new URL(url, import.meta.url)](https://vitejs.cn/vite3-cn/guide/assets.html#new-url-url-import-meta-url)

```js
const imgUrl = new URL('../../static/logo.jpg', import.meta.url).href;
```

##### 3）如果项目引入三方`UMD`或`CommonJS`库，要在 `vite.config.ts`中配置三方库将其转为 `ES` 模块：

`vite` 的开发服务器将所有代码视为原生 ES 模块。因此，`vite` 会先将`node_modules`中以 `CommonJS` 或 `UMD` 形式提供的依赖项转换为 `ES` 模块。

而不在`node_modules`中的文件，需要我们在 `vite.config.ts`中手动配置以进行转换，示例：

```js
// 引入了一个标准的UMD库
// 引入路径不能是相对路径，需要使用别名进行引入
// 三方库建议都放在 static 目录下
import web from '@static/uni.webview.1.5.2.js'

// 在 vite.config.ts 配置需要被转换的文件
export default defineConfig({
    ...
    optimizeDeps: { // dev模式
        include: [
            ...
            '@static/uni.webview.1.5.2.js' // 该配置只接受字符串，需要与引入路径完全相同
        ]
    },
    build: {
        commonjsOptions: { // build模式
            include: [
                ...
                /uni.webview.1.5.2/ // 该配置可接受字符串和正则表达式
            ]
        }
    }
});
```

#### 3. 组件库相关调整

所有组件`v-model`双向绑定的默认 prop 由`value`改为`modelValue`，默认触发事件由`input`改为`update:modelValue`;

该变化对原本使用`v-model`没有影响，仅需注意单向传递时要改为使用`modelValue`而不是`value`，对应的监听事件也应相应修改。

```html
<!-- 无影响 -->
<em-field v-model="msg" />
<!-- 在M8.4中不会生效 -->
<em-field :value="msg" />
<!-- 在M8.4中正确使用 -->
<em-field :modelValue="msg" />
```

#### 4. `css` 调整

##### 1）出于性能考虑，style 中暂不支持 div、p 等 HTML 标签选择器，推荐使用 class 选择器

##### 2）如果项目上存在输出样式变量的 `scss` 文件，需要添加文件名后缀`.module`启用 `CSS Modules`，例如 `common.scss` 改为 `common.module.scss`：

```scss
// common.module.scss文件输出样式变量
$zIndex: 1;
:export {
    zIndexSm: $zIndex;
}
```

```js
// js中引入样式变量
import styles from '../css/common.module.scss';
console.log(styles.zIndexSm); // 1
```

#### 5. $mp 调整为 $scope

在 Vue3 中，组件实例对象下的 `$mp` 调整为 `$scope`

## 跨平台小程序端注意

#### 1. 作用域插槽相关问题

作用域插槽在支付宝小程序存在一些 bug，具体内容请查看文档[组件库下载使用的 M8.4 调整章节](/m8mpdoc/?file=009-UI组件/000-组件库下载使用)的**作用域插槽注意**小节，这里不进行赘述。

#### 2. 部分小程序端事件延迟或调用失败

可在执行事件的元素上添加 `data-eventsync="true"` 属性以解决此问题，如：

```html
<template>
    <button @click="onClick" data-eventsync="true">OK</button>
</template>
```

#### 3. 监听原生的点击事件

在平台小程序端，监听原生的点击事件可以先使用 `tap`。

在 Vue3 中，移除了`.native` 修饰符，所以编译器无法预知 `click` 是要触发原生事件，还是组件的自定义事件，故并未转换成小程序的 `tap` 事件。

#### 4. 微信小程序端真机调试问题

-   Vue3 微信开发者工具真机调试页面空白，如[帖子](https://ask.dcloud.net.cn/question/162915)
-   Vue3 微信小程序真机调试，页面多个输入框、 picker 一起排版时，输入框内容会影响 picker 内容，如[帖子](https://ask.dcloud.net.cn/question/173162)

均可以通过在 `manifest.json` 的 `mp-weixin` 中配置 `minified` 为 `true` 来解决:

```js
{
  "mp-weixin": {
    "setting": {
      // ...其他配置
      "minified": true
    }
  }
}
```

#### 5. 国际化注意

因运行平台限制，目前在平台小程序端不支持插值方式定义国际化,需要使用 `Messages Functions` 定义国际化信息，[参考文档](https://kazupon.github.io/vue-i18n/zh/guide/messages.html#%E5%91%BD%E5%90%8D%E6%A0%BC%E5%BC%8F)。

示例：

```js
const messages = {
    en: {
        greeting: (ctx) => `hello, ${ctx.named('name')}!`
    }
};
```

```html
<template>{{ $t('greeting', { name: 'DIO' }) }}</template>
<!-- 结果：hello, DIO! -->
```

## 插件支持

Vue3 项目中，强烈推荐使用 Vue 官方提供的 VS Code 扩展：`Vue-Official` (之前是 `Volar`) ，它提供了 Vue 单文件组件中的 TypeScript 支持，还伴随着一些其他非常棒的特性。如果你之前已经安装了 Vetur，请确保在 Vue 3 的项目中禁用它。

## Vue3 支持的手机版本

Vue3 支持的范围是：

`Android > 4.4`（具体因系统 webview 版本而异，原生安卓系统升级过系统 webview 一般 5.0 即可，国产安卓系统未使用 x5 内核时一般需 7.0 以上）, `ios >= 10`

`Android < 4.4`，配置 X5 内核支持。
