# 跨端开发 FAQ

## 1、编译到支付宝无法正常获取$slots

这是 uniapp 框架的 bug，在 JS 中获取`$slots`为`undefined`，在模板中默认插槽 `$slots.default` 无法正常判断，但是具名插槽可以使用 `$slots.xxx`进行判断。
暂时只能通过其他方法绕过这个问题。

比如，若`label`插槽为空，就隐藏`label`，此时无法通过`$slots`判断该插槽是否为空，可以通过`:empty`匹配空节点，来修改空节点的样式：

```css
.label {
    color: $cell-label-color;

    &:empty {
        display: none;
    }
}
```

## 2、具名插槽带有连字符，且同时带有后备内容，编译到微信小程序时，无法正常展示

写法例如：

```js
<slot name="right-icon">
    <em-icon name="arrow"></em-icon>
</slot>
```

uniapp 编译到小程序时，会编译成以下代码：

```js
<block wx:if="{{$slots.right-icon}}">
    <slot name="right-icon"></slot>
</block>
<block wx:else>
    <em-icon name="arrow"></em-icon>
</block>
```

所以遇到这种问题，请换一种插槽命名方式，不要使用连字符。

## 3、button 组件无法触发 form 的提交事件，小程序端无法正常获取表单项的值

（1）使用跨端组件库二次封装的 `em-form` 组件时，提交按钮必须使用跨端组件库封装的 `em-button` 组件。同样的，在使用 框架 内置的 `form` 组件时，也只能使用内置的 `button` 组件。否则组件不配套时，点击提交按钮会无法正常触发表单的提交功能。

（2）小程序端在 `form` 内的自定义组件内有 `input` 表单控件时，或者用普通标签实现表单控件，例如评分，无法在 `form` 的 `submit` 事件内获取组件内表单控件值，此时可以使用 `behaviors`。具体请看官方文档：[form | uni-app 官网](https://uniapp.dcloud.io/component/form.html)

在自定义实现的表单控件中添加 `behaviors：uni://form-field`：

```js
export default {  
 name: 'compInput',  
 behaviors: ['uni://form-field'],
}
```

## 4、向子组件传递函数时，函数中的 this 指向问题

在 H5 中，父组件向子组件传递函数，若该函数中使用了 `this`，则 `this` 会正常指向父组件。

而编译到小程序时，传递的函数都会变成子组件的方法，`this` 都会指向子组件，所以该函数可能不会按照预期执行。

可以在子组件调用父组件传过来的函数时，将函数的 `this` 通过 `bind`、`call` 或者 `apply` 方法指向父组件:

```js
this.propFunc.call(this.$root);
```

可参考 `field` 组件和示例。
建议通过 `props` 传递的函数中，不要使用 `this`，或者将传递的方法改为事件由子组件来触发。

## 5、微信小程序的 slot 在 v-for 中无法正常使用

小程序不支持在 v-for 中设置 slot，建议将需要循环渲染的内容拆出来单独封装成一个组件，在拆出来的组件上使用 v-for。

## 6、微信小程序没有作用域插槽

微信小程序不支持作用域插槽，但是框架支持结构插槽。

使用解构插槽时，框架编译到小程序会自动编译成[抽象节点](https://developers.weixin.qq.com/miniprogram/dev/framework/custom-component/generics.html)。 

想要通过`slot`向子节点传参时，请使用解构插槽。

## 7.支付宝不支持文件类型选择上传，只支持图片、视频、音频上传

支付宝小程序不支持`file`类型上传，如果需要上传 pdf 类似文件
请单独使用支付宝小程序-文件管理系统：https://opendocs.alipay.com/mini/02pmiu

## 8、微信小程序使用 image 的 src 导入图片在模拟器上显示，真机调试图片不显示的解决方法

1、若为本地图片，可能是图片路径中含有中文或者空格，将图片路径中文或者空格删去即可。若仍未解决，可以尝试将 src 的相对路径改为绝对路径，可能和文件层深的问题有关。本地图片资源建议都放在 `static` 目录下，且建议使用绝对路径：`/static/images/xxx.png`

2、在线图片时，尝试将图片前缀的 `http` 改为 `https`, 若未解决 可以尝试查看网站域名的合法性。

## 9、支付宝小程序配置 model event 不生效，只能使用默认的 input 事件来实现 v-model

在支付宝小程序中，若要实现`v-model`功能，请将绑定的`props`字段设置成`value`，子组件内部触发值改变时，只能通过触发`input`事件进行修改。

## 10、popup等弹出层进行滚动时，会触发底部页面滚动

在H5和微信小程序中，若要禁止滚动穿透，只需在蒙版的最外层节点上设置`@touchmove.stop.prevent`，若蒙版内部也需要滚动，此时可以使用`scroll-view`组件进行包裹。

但在支付宝小程序中，设置`@touchmove.stop.prevent`是无法禁止滚动穿透的，所以在支付宝中，可以在蒙版弹出时，给底层的内容设置`overflow: hidden`样式，来规避这个问题。

## 11、支付宝小程序v-for中的点击事件无效，报错

需要注意v-for的:key不能使用(item, index)的index作为key，请使用item中的相关唯一标识字段作为for循环的key标识。

## 12、支付宝小程序父页面onLoad中设置的data，传递给子组件，无法在子子组件mounted中获取

需要注意，onLoad为页面级生命周期，mounted为组件级生命周期。

vue生命周期保证顺序执行created > mounted。无法保证页面级生命周期和组件级生命周期的顺序执行。

支付宝小程序子组件的mounted回调先于页面级的onLoad回调执行，所以在子组件mounted中需要使用$nextTick来获取传递过来的数据。

## 13、支付宝小程序页面加载后子组件的没有执行created、mounted等生命周期

支付宝小程序的组件不能作为页面来使用，请排查组件vue是否被写在了router.js中定义成了页面。删除该组件的路由配置即可。

## 14、支付宝小程序span标签添加click事件无效

uni在编译小程序时会把div标签转换为view，span标签转换为text等。

如果在小程序中出现事件绑定无效，可以尝试将标签改为标准的uni内置组件，例如view。
