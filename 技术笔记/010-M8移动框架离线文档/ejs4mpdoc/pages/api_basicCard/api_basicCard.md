# ejs.basicCard

## showBigCardEntrance

卡片底部增加箭头按钮，点击展开卡片扩展页面

**平台差异**

| ejs（H5 应用) | ejs（新点小程序） |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |
| :------------ | :---------------: | :----: | :----- | :--------- | :----------- |
| 不支持        |    支持(4.0.1)    | 不支持 | 不支持 | 不支持     | 不支持       |

**使用示例**

```js
ejs.basicCard.showBigCardEntrance();
```

设置扩展卡片标题

**平台差异**

| ejs（H5 应用) | ejs（新点小程序） |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |
| :------------ | :---------------: | :----: | :----- | :--------- | :----------- |
| 不支持        |    支持(4.0.1)    | 不支持 | 不支持 | 不支持     | 不支持       |

**使用示例**

```js
ejs.basicCard.setBigCardTitle({
    text: '卡片标题',
    success: function(){};
    error: function(){};
});
```

**参数说明**

| 参数 | 参数类型 | 说明           |
| :--- | :------: | :------------- |
| text |  String  | 标题文字, 可选 |
