# ejs.audio

## startRecord

开始录制音频

**平台差异**

| ejs（H5 应用) | ejs（新点小程序） |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |
| :------------ | :---------------: | :----: | :----- | :--------- | :----------- |
| 支持（3.1.2） |   支持（3.1.2）   | 不支持 | 不支持 | 支持       | 支持         |

**使用示例**

```js
ejs.audio.startRecord({
    minDuration: 1,
    maxDuration: 120,
    folderPath: '',
    fileName: '',
    success: function (result) {},
    error: function (error) {}
});
```

**参数说明**

| 参数        |    参数类型     | 说明                                                            | 平台差异说明                                |
| :---------- | :-------------: | :-------------------------------------------------------------- | :------------------------------------------ |
| minDuration | Number / String | 最小允许可录制时长，默认为`1`，单位秒                           | EJS`3.4.0`开始支持，其他平台不支持          |
| maxDuration | Number / String | 最大允许可录制时长，默认为`120`，单位秒，EJS-iOS 不支持默认时长 |                                             |
| folderPath  |     String      | 音频根目录，不传递则有默认的音频存储根目                        | 仅 EJS`3.4.0`开始支持，EJS-iOS 不支持该参数 |
| fileName    |     String      | 音频文件名， 不传递则使用默认的音频文件                         | 仅 EJS`3.4.0`开始支持，EJS-iOS 不支持该参数 |

## stopRecord

停止录制音频，并返回结果

请在`maxDuration`之前停止

**平台差异**

| ejs（H5 应用) | ejs（新点小程序） |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |
| :------------ | :---------------: | :----: | :----- | :--------- | :----------- |
| 支持（3.1.2） |   支持（3.1.2）   | 不支持 | 不支持 | 支持       | 支持         |

**使用示例**

```js
ejs.audio.stopRecord({
    success: function (result) {
        /**
         * 选择文件后返回
         * {
                duration: 3,
                path: '/storage/emulated/0/com.epoint.workplatform/kfld/Temp/1513243453523.amr',
           }
         */
    },
    error: function (error) {}
});
```

**返回说明**

| 参数     | 参数类型 | 说明               | 平台差异说明 |
| :------- | :------: | :----------------- | :----------- |
| duration |  String  | 录音的时长，单位 s |              |
| path     |  String  | 录音的完整本地路径 |              |
