| ejs（H5 应用) | ejs（新点小程序） |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |

**使用示例**

```js
ejs.device.setOrientation({
    orientation: 1,
    success: function (result) {},
    error: function (error) {}

```

| 参数        |    参数类型     | 说明                                                                        |

微信小程序基础库版本 2.4.0 开始，支持通过 `pageOrientation` 字段设置屏幕旋转，具体可看官方文档：[响应显示区域变化](https://developers.weixin.qq.com/miniprogram/dev/framework/view/resizable.html)。

## getDeviceId

获取设备 ID

**平台差异**

| ejs（H5 应用) | ejs（新点小程序） |      H5      | 钉钉 | 微信小程序 | 支付宝小程序 |
| :------------ | :---------------: | :----------: | :--- | :--------- | :----------- |
| 支持          |       支持        | 跨端框架支持 | 支持 | 支持       | 支持         |

**使用示例**

```js
ejs.device.getDeviceId({
    success: function (result) {
        /**
         * {
                deviceId: ''
           }
         */
    },
    error: function (error) {}
});
```

**返回说明**

| 参数      | 参数类型 | 说明                                                                                      |
| :-------- | :------: | :---------------------------------------------------------------------------------------- |
| deviceId  |  String  | 对应的设备 ID。在 非 ejs 环境下，由 uni-app 框架生成并存储，清空 Storage 会导致该 id 改变 |
| uniparams |  Object  | 在非 ejs 环境下，会额外返回 uniAPI 返回的参数                                             |

### ejs-Android 设备 ID 生成原理：

在设备首次启动时，安卓系统会生成一个 64 位的数字（Android 8.0 及以上由系统根据应用签名密钥、用户、设备信息生成；Android 8.0 以下是由系统随机生成），并把这个数字以十六进制字符串的形式保存下来作为设备 ID，设备恢复出厂设置或重装手机系统或者 APK 签名密钥发生更改导致设备 ID 发生变化。

### ejs-iOS 设备 ID 生成原理：

App 首次安装会自动生成 UUID，并保存至系统钥匙串中，系统钥匙串和 App 包名绑定，设备恢复出厂设置或重装手机系统后会发生改变。

## sendTo

发送给其他 app、系统分享功能

**平台差异**

**使用示例**

```js

    title: '测试标题',
    url: 'http://www.liantu.com/',
    imgBase64: '',
    imgURL: '',
    sdPath: '',
    success: function (result) {},
    error: function (error) {}
});
```

**参数说明**

| 参数      | 参数类型 | 说明                   |
| :-------- | :------: | :--------------------- |
| title     |  String  | 标题                   |
| url       |  String  | 链接的 url             |

**注意**

在不同平台，分享的调用方式和逻辑有较大差异。

1. 小程序：不支持 API 调用，只能用户主动点击触发分享。可使用自定义按钮方式 `<button open-type="share">` 或监听系统右上角的分享按钮 `onShareAppMessage` 进行自定义分享内容。

2. H5：如果是普通浏览器，浏览器自带分享按钮；如果是在微信内嵌浏览器中，可调用 js-sdk 进行分享，[参考](https://ask.dcloud.net.cn/article/35380)。

## requestPermissions

```js
    success: function (result) {
        /**
         * {
                resultData: 0
           }
         */
    },

});
```

**权限类别**

| 值  | 对应权限                             |
| :-- | :----------------------------------- |
| `0` | location（定位）                     |
| `1` | storage（存储），微信小程序不支持    |

| `5` | contacts（通讯录），微信小程序不支持 |
| `6` | microphone（麦克风）                 |

**注意**

微信小程序端查询定位权限需要在 `manifest.json` 配置 `permission`字段：

```json
{
    "name": "",
    "appid": "",
    "mp-weixin": {
        "permission": {
            "scope.userLocation": {
                "desc": "你的位置信息将用于小程序位置接口的效果展示"
            }
        }
    }
}
```

**参数说明**

| 参数            |    参数类型     | 说明                                  |
| :-------------- | :-------------: | :------------------------------------ |
| permissionsType | Number / String | 权限类别，默认为`0`，详情见权限类别表 |

**返回说明**

| 参数       |    参数类型     | 说明                                                                                                                                                                        |
| :--------- | :-------------: | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| resultData | Number / String | 申请权限的结果，`0`为申请权限时点了允许，`1`为申请权限时点了拒绝，`2`为由于以前申请权限时点了拒绝并选择不再提示，所以默认拒绝（仅 ejs 环境下支持，非 ejs 环境默认不再提示） |

## isHasVirtualPosApp

检测手机上是否安装虚拟定位软件（仅 Andriod）

**平台差异**

| ejs（H5 应用) | ejs（新点小程序） |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |
| :------------ | :---------------: | :----: | :----- | :--------- | :----------- |
| 支持(4.0.0)   |    支持(4.0.0)    | 不支持 | 不支持 | 不支持     | 不支持       |

**使用示例**

```js
ejs.device.isHasVirtualPosApp({
    success: function (result) {
        /**
         *   未安装，安全：
         *   {
         *       result: '1'
         *   }
         *   安装了，不安全：
         *   {
         *       result: '0',
         *       appname: '应用名称',
         *       packagename: '包名'
         *   }
         */
    },
    error: function (error) {}
});
```

**返回说明**

| 参数        | 参数类型 | 说明                                   |
| :---------- | :------: | :------------------------------------- |
| result      |  String  | '1'：未安装，安全，'0'：安装了，不安全 |
| appname     |  String  | 应用名称，不安全时返回                 |
| packagename |  String  | 包名，不安全时返回                     |
