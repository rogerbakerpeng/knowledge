# ejs.storage

`EJS`容器下的存储，原生容器中的键值对，必须通过`storage`API 才能获取出来

如果需要获取或修改框架键值对，建议通过自定义 API 方式

**注意**

1. 在`H5`和`DD`下，为`localStorage`，浏览器限制 5M 大小，是缓存概念，可能会被清理;

2. `EJS`容器下的存储，必须通过`storage`API 才能获取出来，无大小限制，不是缓存，是持久化的；

3. 各个小程序端为其自带的 storage api，数据存储生命周期跟小程序本身一致，即除用户主动删除或超过一定时间被自动清理，否则数据都一直可用。

4. 微信小程序单个 key 允许存储的最大数据长度为 1MB，所有数据存储上限为 10MB；

5. 支付宝小程序单条数据转换成字符串后，字符串长度最大 200\*1024。同一个支付宝用户，同一个小程序缓存总上限为 10MB。

## getItem

获取键值对

**平台差异**

| ejs（H5 应用) | ejs（新点小程序） |  H5  | 钉钉 | 微信小程序 | 支付宝小程序 | 官方 weex 端 |
| :------------ | :---------------: | :--: | :--- | :--------- | :----------- | :----------- |
| 支持          |       支持        | 支持 | 支持 | 支持       | 支持         | 支持         |

**使用示例**

```js
ejs.storage.getItem({
    key: 'key1', // 或者 ['key1', 'akey2']
    success: function (result) {
        /**
         * {
                key1: 'value1',
                key2: 'value2'
           }
         */
    },
    error: function (error) {}
});
```

**参数说明**

| 参数 |        参数类型         | 说明                                                            |
| :--- | :---------------------: | :-------------------------------------------------------------- |
| key  | String 或 Array[String] | 键名或者键名数组，**EJS 原生容器中会自动给`key`加上`ejs_`前缀** |

**返回说明**

| 参数              | 参数类型 | 说明                                     |
| :---------------- | :------: | :--------------------------------------- |
| (key1, ..., keyn) |  String  | 分别为第`1, ..., n`个 key 以及它的 value |
