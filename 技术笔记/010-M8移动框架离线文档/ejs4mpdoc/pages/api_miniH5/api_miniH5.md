# ejs.miniH5

## navigateTo

打开小程序。

在微信小程序平台中：

1. 需要用户触发跳转，若用户未点击小程序页面任意位置，则开发者将无法调用此接口自动跳转至其他小程序。

2. 需要用户确认跳转, 在跳转至其他小程序前，将统一增加弹窗，询问是否跳转，用户确认后才可以跳转其他小程序。如果用户点击取消，则回调 `fail cancel`

**平台差异**

| ejs（H5 应用) | ejs（新点小程序） |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |
| :------------ | :---------------: | :----: | :----- | :--------- | :----------- |
| 支持          |    支持(3.4.1)    | 不支持 | 不支持 | 支持       | 支持         |

**使用示例**

```js
ejs.miniH5.navigateTo({
    // 新点小程序中跳转示例
    appId: 'appcenter',
    path: './index.html#/appcenter/edit',
    // 为1保活状态关闭小程序，为0不保活,默认为0
    alive: 0,
    extraData: {}
});
```

**参数说明**

| 参数      |    参数类型     | 说明                                                           | 平台差异说明 |
| :-------- | :-------------: | :------------------------------------------------------------- | :----------: |
| appId     |     String      | `必填`，要打开的小程序 appId                                   |              |
| path      |     String      | `选填`，打开指定的页面路径                                     |              |
| alive     | Number / String | 为 1 保活状态关闭小程序，为 0 不保活，默认为 0，迅盟环境不支持 | 仅 ejs 支持  |
| extraData |     Object      | `选填`，需要传递给小程序的额外参数                             |              |

## navigateBack

返回小程序上一页

**平台差异**

| ejs（H5 应用) |           ejs（新点小程序）            |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |
| :------------ | :------------------------------------: | :----: | :----- | :--------- | :----------- |
| 不支持        | 支持(3.4.1)<br>（ejs-weex 环境不支持） | 不支持 | 不支持 | 支持       | 支持         |

**使用示例**

```js
ejs.miniH5.navigateBack({
    extraData: {},
    useRouter: true
});
```

**参数说明**

| 参数      | 参数类型 | 说明                                                      | 平台差异说明 |
| :-------- | :------: | :-------------------------------------------------------- | :----------: |
| extraData |  Object  | `选填`，需要传递给上一个小程序的额外参数, 迅盟环境不支持  | 仅 ejs 支持  |
| useRouter | Boolean  | `选填`, 是否是单页应用，关闭时使用路由返回，默认为`false` | 仅 ejs 支持  |

## close

关闭小程序

在微信和支付宝小程序平台中，必须要有点击行为才能成功调用。

**平台差异**

| ejs（H5 应用) |            ejs（新点小程序）            |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |
| :------------ | :-------------------------------------: | :----: | :----- | :--------- | :----------- |
| 不支持        | 支持(4.0.0) <br>（ejs-weex 环境不支持） | 不支持 | 不支持 | 支持       | 支持         |

**使用示例**

```js
ejs.miniH5.close({
    // 为1保活状态关闭小程序，为0不保活，默认1
    alive: 1,
    extraData: {
        key1: 'value1'
    },
    success: function () {}
});
```

**参数说明**

| 参数      |    参数类型     | 说明                                         | 平台差异说明 |
| :-------- | :-------------: | :------------------------------------------- | :----------: |
| alive     | Number / String | 为 1 保活状态关闭小程序，为 0 不保活，默认 1 | 仅 ejs 支持  |
| extraData |     Object      | 关闭小程序时的回调参数                       | 仅 ejs 支持  |

## applyCard

小程序支持下载卡片资源

**平台差异**

| ejs（H5 应用) |             ejs（新点小程序）             |   H5   | 钉钉   | 微信小程序 | 支付宝小程序 |
| :------------ | :---------------------------------------: | :----: | :----- | :--------- | :----------- |
| 不支持        | 支持(4.0.3-a) <br>（ejs-weex 环境不支持） | 不支持 | 不支持 | 不支持     | 不支持       |

**使用示例**

```js
ejs.miniH5.applyCard({
    // 支持配置强制更新 isforce 参数，1 不再执行判断逻辑、直接更新  0 正常更新
    isforce: '0',
    // 传入卡片 appkey、version、cardguid、isdebug
    appkey: '',
    version: '',
    cardguid: '',
    isdebug: '',
    success: function (result) {},
    error: function (err) {}
});
```

**参数说明**

| 参数     | 参数类型 | 说明                                               |
| :------- | :------: | :------------------------------------------------- |
| isforce  |  String  | 强制更新, 1 不再执行判断逻辑、直接更新, 0 正常更新 |
| appkey   |  String  | 传入卡片 appkey                                    |
| version  |  String  | 传入卡片版本                                       |
| cardguid |  String  | 传入卡片 cardguid                                  |
| isdebug  |  String  | 是否是调试卡片 isdebug                             |
