## 一、建设内容的两个目标（写法示例）

1. 遵循《信息技术产品安全可控评价指标》体系：通过中央处理器、操作系统、办公套件和通用计算机产品适配，确保关键信息技术自主可控，避免国外软硬件预装"后门"隐患。
2. 提升系统信息安全级别、通过**三级等保测评**：对用户密码国密加密、三权分立、CA 签章等关键环节重点改造 + 全系统三级等保合规性改造。

## 二、总体设计

### 标准规范（需遵循）

- GB/T 36630.1~5-2018《信息技术产品 安全可控评价指标》第 1~5 部分：总则 / 中央处理器 / 操作系统 / 办公套件 / 通用计算机
- 《商用密码管理条例》（1999 年国务院令第 273 号）
- 《信息安全等级保护商用密码管理办法》（国密局发 ]11 号）及实施意见（国密局发 ]10 号）

### 总体架构（5 方面）

| 方面 | 内容 |
|---|---|
| 基础硬件环境改造 | 国产 CPU、国产操作系统服务器升级；国产存储设备、国产安全设备 |
| 基础软件环境改造 | 国产数据库、国产中间件、国产杀毒软件 |
| 办公套件替换 | 流式软件（WPS）、版式软件（OFD）、电子签章 |
| 应用系统改造 | ① 能在国产化软硬件+办公套件下正常运行；② 网络通信层改造（SSL 安全接入网关建立加密传输通道）；③ 应用安全改造（关键环节国密 SM2/SM3/SM4） |
| 客户终端替换 | 国产 CPU PC、国产操作系统、国产浏览器、国产打印机 |

### 安全性设计（3 方面）

1. **软硬件基础环境安全**：芯片、操作系统、数据库三个层面自主可控。
2. **网络和通信安全**：部署 SSL 安全接入网关，传输中做身份认证、防截获、防假冒、防重用，按敏感程度对字段加密。
3. **系统应用安全**：国密算法——
   - **SM2** 椭圆曲线公钥密码：SM2-1 数字签名、SM2-2 密钥交换协议、SM2-3 公钥加密；
   - **SM3** 杂凑算法：数字签名与验证、消息认证码生成与验证、随机数生成；
   - **SM4** 分组对称算法：数据加解密，保证机密性。

## 三、原方案简介（模板示例：住建部改造项目）

业务服务器示例共 18 台：Windows 2016/2012 + CentOS 7 混合，虚拟机+物理机；数据库 MySQL×15（另 1 台 pgsql）；中间件 Tomcat×9（另 1 台 kong）。模板提示：服务器多时同用途可合并为"数量"列；涉及数据交换的项目数据库应细分为前置库/业务库/专题库，便于后续适配不同国产数据库。改造后对照清单全部替换为：中标麒麟 v7.0 + DM7.0×12 + TongWeb 6.1×9 + 长城终端×30 + WPS×30 + OFD×30。

## 四、国产化适配解决方案

### 4.1 基础硬件

- 服务器：x86 Intel → **华为 TaiShan（ARM 鲲鹏）**双路机架服务器。
- 虚拟化：**华为 FusionSphere**（ARM 服务器部署虚拟化软件，提供企业级/运营级虚拟数据中心与跨站点容灾）。

### 4.2 基础软件

- 操作系统：Windows/CentOS → **中标麒麟通用服务器操作系统 7.2+**。
- 容器中间件：Tomcat → **东方通 TongWeb**（内核提供底层通信、线程、配置、时间、日志；架构含内核及底层服务、构件容器、J2EE 服务、界面/工具四大部分）。
- 数据库：SQLServer/Oracle/MySQL → **达梦 DM7**（类 JAVA 虚拟机技术，兼顾 OLTP 和 OLAP）；需适配数据库结构初始化（数据表、存储过程、序列、触发器等）与各功能模块访问/存储改造。

### 4.3 办公套件

- 版式文件：PDF/Word → **OFD**（国产版式标准；支持阅读浏览、文档操作、图文注释、原笔迹手写签批、对接电子印章；骑缝章、交叉盖章、签章雾化；支持 PDF→OFD、Word→OFD 转换）。
- 流式编辑：Word → **金山 WPS**（兼容中标/麒麟/深度/中科方德/普华/思普/一铭操作系统；深度兼容龙芯/飞腾/兆芯/申威/众志 CPU）。

### 4.4 网络和通信安全

**SSL 握手 6 阶段**（配 doc2_img06 时序图）：
1. 客户端明文发起请求（版本、加密套件候选、压缩算法候选、随机数、扩展字段）；
2. 服务端响应协商结果（version、cipher suite、compression method、random_S）；
3. 客户端校验证书合法性；
4. 客户端产生 Pre-master 随机数并用证书公钥加密发送；
5. 服务端私钥解密，计算此前所有接收信息 hash 验证数据与密钥；
6. 握手结束，双方用协商密钥与算法加密通信。

**硬件 SSL 应用交付网关（国密版）功能**：RSA/SM2 双证书同实例自适应（按客户端算法能力自动适应）、单双向认证、动态黑名单（LDAP/HTTP/手工上传，B64/DER 格式）、多站点证书、多证书链、格尔/CFCA/SHECA 等多 CA 证书、证书信息经 Cookie/HTTP header 传给后台应用（免证书接口开发）、多 SSL 服务、应用重定向、后端负载均衡、国密 SM1/SM2/SM3/SM4、GMVPN 协议、管理员三权分立、备份恢复、SYSLOG 日志、Web 在线升级、性能检测、双机热备、自负载均衡、网卡聚合。

### 4.5 国密算法适配改造

两大方面：① 系统能在国产化基础软硬件环境、办公套件下正常运行；② 加密算法国密化。

改造点（参考电子交易/OA，各条线需独立编写）：

| 环节 | 原算法 | 改造后 |
|---|---|---|
| API 接口交互数据（支撑/支付/物流等子系统间） | 明文 | **SM4** 对称加解密传输 |
| API 身份认证 token 的生成/传输/使用 | — | **SM4** 加解密 |
| 登录密码、验证码 | MD5 | **SM3** |
| 电子签章 | RSA | **SM2**（所有用签章环节） |

**性能对比实测数据**：

- **SM2 vs RSA**（10000 次）：签名 4513ms = RSA-2048 的 **3 倍快**（29.51% 耗时）；验签 3448ms = RSA-2048 的 **1/4 速度**（407% 耗时）；加密 4327ms = RSA-2048 的 **1/7 速度**（714% 耗时）；解密 3899ms = RSA-2048 的 **4 倍快**（26% 耗时）。
- **SM3 vs SHA1**（118.24M 文件）：BC-SM3 2015ms vs SHA1 503ms——**约为 SHA1 的 1/7 性能**（MD5 410ms，比 SM3 快）。
- **SM4 vs 3DES**：加密 5108M 文件 3755s vs 3DES 2966s（略弱，79% 速度）；解密 6815M 文件 324s vs 3DES 722s（**2 倍多快**）。

### 4.6 国产客户终端

- 终端：**长城客户端（台式机/笔记本）+ 飞腾 FT-1500A**（64 位 ARMv8、28nm，可替代 Intel 中高端"至强"），预装银河麒麟桌面 OS。长城安全电脑除 CPU 外软硬件全部自研（安全硬盘、安全 BIOS）。
- 桌面 OS：**银河麒麟桌面操作系统 4.0.2+**（x86/x86_64 + 飞腾等国产 CPU；默认集成搜狗输入法、WPS、永中 office、福昕阅读器）。
- 浏览器：IE → **火狐 firefox**（按火狐插件规范改造 ActiveX 控件，保证 CA 签名验签、加解密、OFD 版式、CAD 预览等功能可用）。

## 五、实施七步（适配相关工作）

策略：**分步实施，从混合使用阶段过渡到全面替代阶段**（基础硬件混合、国产软件跑在非国产硬件上、终端混合）。

1. **环境搭建和应用迁移**：系统调研 → 制定迁移计划 → 搭建迁移测试环境（单元+性能测试验证可行性）→ 迁移实施 → 迁移测试 → 业务切换。
2. **全面适配测试**：功能测试（界面/数据/操作/逻辑/接口）+ 性能测试（负载/压力/疲劳/大数据量/故障定位与调优）。
3. **升级改造**：产品功能 + 项目定制功能分别适配。
4. **应用部署和数据迁移**：先模拟迁移环境测试，成功后正式迁移，调整数据库参数与性能。
5. **适配验证**：兼容性验证、性能验证（登录/表单打开/流程发送等环节压测）、业务流畅性验证（发现非国产环境依赖的功能缺失并建立替代方案）、数据迁移验证（补漏确保一致性）。
6. **试运行和正式运行**：**并行切换**——老业务原系统、新业务新平台，制定并行时间表。
7. **商用密码评测**：按《商用密码管理条例》从《商用密码应用安全性测评机构目录》选机构评测，目标通过**商用密码三级**；需建立密钥管理体系（生成/存储/分发/导入导出/使用/备份恢复/归档/销毁）与密码安全管理制度。
