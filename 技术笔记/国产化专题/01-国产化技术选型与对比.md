## 国产化改造的 5 个方面

国产化适配改造包括：**基础硬件环境改造、基础软件环境改造、办公套件替换、应用系统改造、客户终端替换** 5 个方面。项目具体需要哪几个方面视客户需求而定。

- **基础硬件环境**：国产 CPU、操作系统、存储设备、安全设备替换。服务器层面差异核心在 CPU——CPU 架构不同 → 指令集不同 → 配套操作系统版本不同。
- **基础软件环境**：运行在操作系统上的中间件（如 Tomcat）、数据库（如 MySQL）等支撑业务程序的软件。

## 性能测试结论

### 华为鲲鹏（ARM）

- **结论：Java 应用鲲鹏 ： Intel ≈ 1 : 2**。即原 Intel 4核8G 支撑业务 200 并发 → 换鲲鹏需 8核8G。
- 配置建议：客户对性能有要求时，在原非国产化推荐配置基础上**将服务器 CPU 翻倍**。
- 测试详情：在公司租借华为服务器、华为公有云、华为实验室 3 个环境对 OA 压测对比；华为公有云团队压测 JVM 结论为**性能比 60%**。

### 龙芯（MIPS）

- **结论：Java 应用龙芯 ： Intel ≈ 1 : 20**。
- 龙芯**暂无对应虚拟化平台**，无法提供虚拟机、只能物理机；客户对性能有要求时，建议**单台物理服务器部署 1~2 个 Java 应用**。

## 实务要点

1. 选型以 CPU 架构为纲：确定了 CPU 就基本确定了操作系统与可用的软件适配范围。
2. 公司主流路线 = 鲲鹏 ARM + 中标麒麟/openEuler/Anolis + TongWeb + 达梦（或保留 MySQL）。
3. Redis / Nginx / RabbitMQ 暂无成熟国产替代，属甲方沟通决策点。
4. 龙芯方案性能代价极大（1:20）且无虚拟化，仅在甲方硬性要求时使用并控制单机应用密度。
