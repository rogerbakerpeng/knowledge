## 画面要点（原始记录）

**整体**：Epoint 开评标系统标准版平台，评标工作人员（刘子航）在"技术标非横向打分(3/4)"环节评审"技术标单价文件多文字效率测试2"标段。

**左侧评标流程步骤条**：
- 已完成（绿）：公布投标人 → 评标准备
- 当前大环节（蓝高亮）：技术标大模型评审，内含子步骤：评审规则确认 → 智能评审 → **技术标非横向打分（当前）** → 技术标横向打分
- 未到（灰）：初审评审 → 详细评审 → 评标报告

**中部评审区**：
- 单位列表：单位[1]（选中）/ 单位[2] / 单位[3]
- 评审结果汇总-单位[1]：AI评审列两指标——施工进度计划和各阶段进度的实施要求和保证措施(0.7~1.0)=0.91；质量技术保证措施(0.7~1.0)=0.93
- 评审结果明细卡片（可展开）：AI评分 0.91 + **专家复核 0.91 分（可编辑输入框）**
- 每条评分标准展开为四层证据链：
  1. 评审标准（如"工序衔接科学性，关键路径划分清晰、逻辑性强"）
  2. 逐条得分理由（如"未明确提出工序衔接关系，未达优秀标准 → 得0.07分"）
  3. **响应摘要**（绿色引文，如"各工序之间存在短暂的前后衔接关系，土方工程为基础施工"）
  4. **第N页**（蓝色链接，可跳投标文件原文页，如 第168页/第171页/第163页/第164页/第233页/第350页）

**右侧辅助评标 AI 面板**（滑出式）：
- 提示语"已接当前标段，请基于预处理材料提问"
- 输入示例："当前阶段招标文件中评审办法是shen…"，支持 **@单位** 上下文引用
- 底部内嵌**屏幕录制**控件（计时 00:00:27 + 红色停止按钮，评标过程留痕）

## 可复用要点提炼

1. **人机协同评分模式**：AI 初评分与专家复核分并排对照，复核值可改——大模型给参考分，专家拥有最终裁量权。
2. **四层证据链结构**：评审标准 → 得分理由 → 响应摘要 → 原文页码跳转，每个扣分点都可溯源到投标文件具体页，是"AI 评审可解释性"的界面化范式。
3. **流程内嵌大模型环节**：评标主流程中出现"技术标大模型评审"专属阶段（规则确认→智能评审→非横向→横向打分），而非独立工具。
4. **侧边 AI 问答面板**：限定"基于预处理材料提问"+@单位引用，把对话约束在标段语料内，防止幻觉外溢。
5. **过程留痕**：录制控件内嵌界面，满足评标音视频档案合规要求。
