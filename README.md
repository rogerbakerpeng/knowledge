# 本地 AI 知识库

记录可复用的技术经验与工作流程，便于团队查看和持续补充。

从[知识库总索引](index.md)开始，或直接阅读[Epoint 新点应用启动](流程规范/010-Epoint应用启动/index.md)。

## 目录说明

- [流程规范](流程规范/index.md)：工作流程、开发规范、启动与部署步骤。
- [技术笔记](技术笔记/index.md)：技术方案、配置说明、踩坑记录、命令速查。
- [FAQ](FAQ/index.md)：常见问题与解答。
- [项目](项目/index.md)：按项目归档的背景、需求、方案和进展。

- [技能](skill/index.md)：yuan脑爆调研、yuanskill-pro提示词与技能优化，附Codex安装说明。

## 使用与维护

```powershell
git clone https://github.com/rogerbakerpeng/knowledge.git
```

新增资料放入对应分类并补充索引。技能应包含 SKILL.md、必要参考与脚本，并提供安装说明；较长内容按主题拆分。

共享内容不要包含账号密码、访问令牌、机器授权文件、Maven 认证配置、登录态、数据库导出或未经脱敏的原始日志。机器路径与历史版本仅供参考，使用前按本机环境核实。机器授权需各自合法获取，不随本仓库分发。
